# UI 变更单 #015：模式一屏切换 + 进程只读（#50）

- 状态：已实现（2026-10-29；本单替换 #012 的四视图流程与 #008 的进程结束入口）
- 依据：`docs/dual-mode.md`、`docs/host-ops.md`、`docs/engineering/adr/ADR-0007-host-ops-ssh-via-hub.md`
- 路由：不新增路由/侧栏；节点设置、节点概况、进程抽屉沿用既有入口

## 1. 作用域

| 位置 | 变化 |
|---|---|
| `/hubs/:hubId/settings` 节点模式卡 | 徽章只保留 `组网 Hub / Caddy 网关 / 未确认`；unknown 时禁用切换 |
| 模式切换抽屉 | 四视图 → **一屏**：当前模式、阻断列表（带修复入口）、影响摘要（一条 warning + 一个确认框）、[取消] [确认切换] |
| 切换中 | 按钮 loading（不再有 Steps/进度页）；成功/失败都在同屏 Banner 展示 |
| `/hubs/:hubId` 概况 | 页头模式徽章同上，无交互 |
| 主机运维 → 进程抽屉 | 只读：保留 CPU/内存排序 Top 列表与详情；移除行内「结束」、强制开关、确认对话框与 toast |

## 2. 模式抽屉（L2）

- 顶部：当前模式徽章 +「当前为…」。
- 阻断：红色 Banner 列表；每项可带「去处理」链接；有阻断时确认按钮禁用并显示原因。
- 影响摘要：琥珀 Banner（API 生成的一句话）+ Checkbox「我已了解以上影响」；不勾选不可切换。
- 底部按钮 ≤2：[取消] [确认切换 · 目标模式]；切换中按钮 loading，文案「切换中…」。
- 失败：同屏红 Banner + 错误码 + 重试提示 +「查看诊断」；不提供「撤销切换」。
- 四态：空（未配置/unknown）、加载 Skeleton、错误 Banner + 重试、离线禁用。

## 3. 进程抽屉

- 列：PID、CPU、命令、用户、内存、启动时间（#014 的低优先级列规则不变）。
- 行点击打开只读详情（KeyValue + CodeBlock）；无行内动作、无批量选择。
- 非 root 主机：中性 Banner「进程列表只读，面板不提供结束进程操作」。
- 移除的动作注册 `hostOps.kill` 与 i18n 文案；审计不再产生 `hostops.killed`。

## 4. 组件与文案

- 组件：Card、Badge、Banner、Button、Checkbox、Drawer、Link、Stack、Row、Table、Dialog、KeyValue、CodeBlock、Segmented；不新增组件/样式/依赖。
- 文案：影响摘要由后端返回中文一句话；前端只提供标题与勾选标签；不再逐条列后果数量。
- 手机（390）：抽屉全屏；阻断/影响纵向堆叠；底部按钮可用。

## 5. 验收

- blocker 出现时按钮禁用且可跳转修复；影响摘要必须勾选才能切换；成功同屏提示并刷新徽章。
- unknown/离线不可进入切换；失败可重试，配置不被删除。
- 进程抽屉无任何结束进程入口；现有测试断言 `更多操作` / `结束` 不存在。
- 浅/深/390 截图在实现 PR 中附。
