# UI 变更单 #014：界面一致性与可访问性修复

- 状态：已实现（2026-10-29）
- 路由：无新增路由 / 无新增动作
- 依据：UI 自查（frontend-design 审查）+ `docs/ui/ui-spec.md` §3.1 / §3.4 / §4.13a / §4.14 / §4.21 / §4.22 / §4.23 / §6.2 / §6.3

## 1. 作用域

全局：顶栏、侧栏（平板图标栏）、浮层（抽屉/对话框/菜单/Toast）、表格列宽、登录页。节点层页面仅调整列优先级标记（站点、转发），不改作用域归属。

## 2. 流程

不涉及新的 F 流程；均为现有 F3/F4/F5/F6/F7/F9 的展示与交互修复。

## 3. 页面与模板

- T1 概览：改为 2fr / 1fr 分栏（左列表、右「需要处理 + 最近活动」）；移除无数据的「应用数量」统计卡（无来源时不再显示占位 `—`）。
- 节点概况：去掉与标题重复的作用域标签（对 S4「节点层三处显示作用域」的显式例外：标题即节点名，面包屑仍显示节点）。
- 其余页面布局不变。

## 4. 入口

无新增创建入口；S1–S3 不变。

## 5. 动作清单

无新增动作；菜单项仍由 `registry/actions.ts` 提供。

## 6. 使用的组件

使用：Button、Menu、MenuButton、Drawer、Dialog、Table、Card、Stat、Split（新增，见 ui-spec §4.13a）、BrandMark（内置标记，非新组件）。
变更：
- Menu 改为 portal + fixed 定位，避免被表格单元格裁切；滚动/缩放时关闭。
- Drawer/Dialog 增加焦点陷阱与关闭后焦点归还。
- Button 的 `disabledReason` 由外层包裹元素承载（title 可悬停）。
- Table 列宽改为弹性（name 26%，其余弹性，number/time/sync/actions 固定），`priority: 'low'` 列在 <1024 隐藏。
- 新增图标：menu / sun / moon / search / brand（24 网格、1.75 描边）。

## 7. 新文案

无新增用户文案（复用 `zh.common` 与 `zh.app`）；登录页新增「控制面」状态行，取自 `zh.app.controlPlane`。

## 8. 状态覆盖

- 空 / 加载 / 错误 / 离线 / 同步：不变。
- 菜单：不在表格内被裁切；打开后滚动即关闭。
- 禁用按钮：悬停外层可见原因。

## 9. 手机

- <640：侧栏抽屉（原有），顶栏新增搜索图标按钮，命令面板入口不再丢失。
- 640–1023：侧栏改为 56px 图标栏（ui-spec §3.3 断点），导航只显示图标。
- 浮层进出场 200ms；`prefers-reduced-motion` 时为 0。
- 复审修正：手机顶栏保留用户菜单图标（仅隐藏用户名），退出登录仍可达；菜单内部滚动不触发“滚动关闭”。
