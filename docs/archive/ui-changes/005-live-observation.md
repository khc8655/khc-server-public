# UI 变更单 #005：节点实时观测（6.4a）

- 状态：已获主人批准（继续实现，2026-10-26）
- 依据：`docs/live-observation.md`（本仓库；旧 wireguard PR #3 仅历史来源）
- 路由：节点概况 `/hubs/$hubId` 新增只读「实时观测」卡片；节点创建表单增加观测入口

## 1. 作用域与流程

- 节点层只读状态，不新增业务对象；不提供任何写操作。
- 页面打开且可见时才连接；页面隐藏断开，恢复可见重新取票连接。
- 断线/未配置 → 显示「降级 · 控制面快照」，不阻塞页面其余操作。

## 2. 页面与组件

| 位置 | 内容 |
|---|---|
| 节点概况 | `Card`「实时观测」：状态 Tag（实时/连接中/降级/未配置）、最近推送时间、只读提示、观测入口域名 |
| 节点创建抽屉 | 可选字段「实时观测地址」（`https://hub.example.com`，用于 `/_live/`） |

组件：Card、KeyValue、Tag、Banner/InlineError、TextInput；不新增自定义样式。

## 3. 数据/动作

- 读：`POST /api/v1/nodes/:id/live-ticket`（scope=live，origin=console origin）→ `wss://<liveEndpoint>/_live/` 首消息认证。
- 无写动作；nudge 不在本期 UI 暴露（后续再评估）。

## 4. 状态覆盖

- 未配置 `liveEndpoint` → 「未配置」+ 说明；
- 连接中/实时/降级（含错误原因）；
- 页面隐藏 → 断开；重新可见 → 自动重连；
- 票过期/连接失败 → 重新取票，失败显示降级。

## 5. 手机

卡片纵向排列，状态与时间单行；不新增横向滚动。

## 6. 验收

staging 节点 `liveEndpoint=https://example.com`，打开节点概况应显示「实时」并在约 1 秒内更新；断开网络/Caddy 后显示「降级」，恢复后自动回到「实时」。
