# 0. 这份规范怎么用

**写给谁**：主要写给执行前端开发的 Agent，其次是主人做验收。

**为什么这么细**：Agent 写 UI 的常见问题是“局部合理、整体乱”：每个页面单看都能用，合在一起按钮位置、确认方式、文案、创建入口各不相同。所以这份规范按三层来约束：

1. **结构层**（第 1–2 章）：作用域与流程。决定“什么东西在哪里、从哪里进、做完去哪里”。**这一层错了，组件再漂亮也是乱的。**
2. **组件层**（第 3–4 章）：令牌与每个组件的尺寸、状态、参数、文案、禁止项。决定“长什么样、怎么动”。
3. **执行层**（第 7 章）：Agent 的工作约定——先交“UI 变更单”获批再写代码、目录分层、组件参数白名单、路由与动作集中登记、旧版问题对照、功能暴露准入。约束靠规范和评审，不额外加 CI 检查，避免拖慢发版。

**用词等级**：**必须**（违反即退回）、**应该**（例外须在 PR 写明理由）、**可以**。本文默认语气为“必须”。

**配套文件**：`proto/tokens.css`（令牌唯一来源）、`proto/components.css`（参考实现）、`proto/src_*.html`（样稿源）、`shots/*.png`（样稿截图，附录）。

# 1. 作用域模型（最重要的一章）

## 1.1 两层作用域

整个产品只有两层：

| 层 | 包含 | 进入方式 | 侧栏 |
|---|---|---|---|
| **全局层** | 概览、节点列表、活动（全部）、设置（管理员、DNS 凭据、更新通道等全局资源） | 打开面板默认在此 | 全局侧栏：概览 · 节点 · 活动 · 设置，下方列出所有节点作快捷入口 |
| **节点层** | 某一个节点里的一切：概况、WireGuard（客户端）、站点、转发、证书、应用、该节点活动、节点设置 | 点击任意节点 | 节点侧栏：← 全部节点 / 节点切换卡 / 概况 · WireGuard · 站点 · 转发 · 证书 · 应用 │ 活动 · 节点设置 |

节点是**容器**。客户端、站点、转发、证书、应用都是节点里的**内容**，它们没有脱离节点的存在形式。

## 1.2 作用域规则（S1–S12）

| # | 规则 |
|---|---|
| S1 | **创建入口唯一**：每类对象只有一个“添加”入口，位于其父容器的列表页页头右侧。节点 → 全局层「节点」页；客户端 → 节点层「WireGuard」页；站点、转发、证书、应用 → 各自节点层页面。 |
| S2 | **全局层不出现任何节点内对象的创建、编辑、删除操作**。概览页没有任何“添加”按钮，它只负责“看”和“分诊”（点进去处理）。 |
| S3 | **同一屏不出现两个不同层级对象的创建按钮**（例如“添加节点”和“添加客户端”永远不同屏）。 |
| S4 | **作用域始终可见**：节点层的每个页面，必须同时有 ① 侧栏顶部节点切换卡（名称 + 状态点 + 地区）② 面包屑 `节点 › tyo-1 › WireGuard` ③ 页头作用域标签 `[▤ tyo-1]`。抽屉和对话框标题副文本必须写节点名（`添加客户端 · tyo-1`）。 |
| S5 | **跨节点只读**：跨节点查找只有两条路——⌘K 命令面板、概览“需要处理”。它们的结果都是**跳转进入节点层**，不提供跨节点就地编辑。 |
| S6 | **切换节点保留功能位置**：在 tyo-1 的 WireGuard 页切换到 hk-1，落到 hk-1 的 WireGuard 页；有未保存修改时先拦截确认。 |
| S7 | **流程不跨层**：一个流程（向导、抽屉）只操作一个层级的对象。添加节点向导里**不允许**顺手添加客户端；向导完成页只给“去添加第一个客户端”的链接，点击后进入节点层再走 F3。 |
| S8 | **对象不搬家**：v2 不支持把客户端/站点/应用从一个节点移到另一个节点。需要时在新节点重建、旧节点删除。 |
| S9 | **全局资源引用**：DNS 凭据等全局资源只在「设置」里创建和修改。节点层表单引用它时用下拉选择，旁边提供“管理凭据”链接（跳到设置，完成后可一键返回原表单，表单内容保留）。 |
| S10 | **路由即作用域**：所有节点层路由以 `/hubs/:hubId/` 开头；全局层路由不得携带节点内对象 ID。路由清单里每条路由声明 `scope: 'global' | 'hub'`（见 7.4）。 |
| S11 | **级联说明**：删除或停用父容器（节点）时，确认文案必须列出受影响的子对象数量（“将移除 2 个客户端、1 个应用、1 张证书”）。 |
| S12 | **新增对象类型时，先在本表登记它属于哪一层、父容器是谁、唯一创建入口在哪**，再做其他设计。 |

## 1.4 页面模板

| 模板 | 结构（自上而下） | 规则 |
|---|---|---|
| **T1 概览** | 页头（标题 + 一句现状）→ 统计条（≤4 张）→ 左：主列表 / 右：需要处理 + 最近活动 | 不放创建按钮；每项都可点进对应页面 |
| **T2 列表** | 页头（标题 + 作用域标签 + 摘要 + 主操作）→ 可选告警横幅（≤2）→ 卡片：工具栏 + 表格 | 主操作只有一个；行点击打开详情 |
| **T3 对象详情** | 页头（图标 + 名称 + 状态徽章 + 元信息 + 同步状态 + 操作）→ Tabs → 内容 | Tab ≤ 5；对象自身操作在页头 |
| **T4 配置** | 未保存横幅（有修改时）→ 左分区导航（≤6）+ 右表单 → 底部保存条（放弃修改 / 保存并生效）→ 页面最底部危险区 | 危险区操作单独确认，不随保存条提交 |
| **T5 向导** | 顶栏（× 取消 + 流程名 + “进度自动保存”）→ 步骤条 → 本步标题与说明 → 本步内容 → 底部（上一步 / 下一步） | 无侧栏；内容宽 720 居中；每步一个主按钮 |

# 2. 流程规范

每个流程按同一格式定义：**入口 · 前置条件 · 步骤 · 中途退出 · 异常与恢复 · 完成落点 · 审计事件**。新流程必须按此格式写进本章才能实现。

## F1 添加节点（全局层，向导 T5）

| 项 | 规定 |
|---|---|
| 入口 | 唯一：`/hubs` 页头「添加节点」。零节点时，概览和节点页空状态的主按钮也指向这里（同一个路由，不算第二入口）。 |
| 前置 | 无 |
| 步骤 1 基本信息 | 字段：名称（必填，`[a-z0-9-]{2,24}`，唯一，失焦查重）、地区备注（可选）。主按钮「下一步」。**点击即创建一条“等待接入”状态的节点记录**。 |
| 步骤 2 安装 Agent | 显示一次性安装命令（30 分钟有效、单次使用）、系统选择分段（Debian/Ubuntu · Alpine · 手动安装）、复制按钮、“查看脚本内容”。下方实时卡片：等待连接（旋转环 + 已等待时长）+ 3 个子步骤（命令已生成 / 首次连接 / 上报系统信息）。**连接成功后自动进入下一步**；「下一步」在连接前禁用。 |
| 步骤 3 初始化网络 | 显示节点上报的系统信息（架构、内核、公网 IP 探测结果，可改）。字段：WireGuard 监听端口（默认 51820/udp，实时查占用）、隧道子网（默认自动分配不重叠的 /24）、入口模式（站点优先 / 代理优先，带一句解释）。主按钮「创建网络」→ 变为任务进度（L1 内联，不开抽屉）。 |
| 步骤 4 完成 | 摘要卡（名称、地址、接口、子网）+ 两个链接：「添加第一个客户端」（→ `/hubs/:id/wireguard?drawer=new`）、「查看节点」（→ `/hubs/:id`）。主按钮「完成」→ `/hubs/:id`。 |
| 中途退出 | 顶栏「× 取消添加」：步骤 1 之后弹 L2 确认（“删除尚未接入的节点 sg-2？”）；直接关闭浏览器不删除，节点以“等待接入”留在列表，行内「继续添加」回到当前步骤。 |
| 异常 | 命令过期 → 卡片变琥珀“命令已过期”+「重新生成」；10 分钟未连接 → 展开“排查清单”（出站 443 是否放行、时间是否同步、是否 root、复制错误日志的命令）；架构不支持 → 红色横幅，「下一步」禁用；端口占用 → 字段错误并给出替代端口。 |
| 落点 | `/hubs/:id`（节点概况） |
| 审计 | `hub.created`、`hub.enrolled`、`hub.network_initialized` |

## F2 进入与切换节点

- 从节点列表、侧栏节点快捷列表、概览节点表、⌘K 进入，统一落到 `/hubs/:id`。
- 节点切换卡点击 → 下拉列出所有节点（状态点 + 名称 + 地区），键盘可上下选择；切换遵守 S6。
- 离线节点照常可进入、可编辑；页面顶部显示灰色横幅“fra-1 离线 2 小时，改动会在上线后生效”。

## F3 添加客户端（节点层，抽屉）

| 项 | 规定 |
|---|---|
| 入口 | 唯一：`/hubs/:id/wireguard` 页头「添加客户端」（键盘 `N`）。 |
| 前置 | 节点已完成 F1 步骤 3（有 WireGuard 接口）。未完成时页面显示空状态“这个节点还没有初始化网络”+「继续添加节点」。 |
| 表单 | 名称（必填，节点内唯一）、设备类型（分段：手机 / 电脑 / 站点），隧道地址（自动，可改，实时查冲突）、路由（全部流量 / 仅内网 / 自定义 CIDR）。高级（默认折叠）：预共享密钥（默认开）、保活间隔（手机默认 25 秒）、DNS。 |
| 保存 | 主按钮「保存并生效」，底部说明“保存后约 2 秒生效”（节点离线时改为“tyo-1 离线，上线后生效”）。 |
| 结果视图 | 保存成功后**同一抽屉切换为结果视图**（不关闭、不另开弹窗）：状态徽章 + 二维码 + 下载 .conf + 复制文本 + 提示“只显示这一次”。主按钮「我已导入，完成」。关闭时若用户没下载/复制过，L2 确认“配置还没保存，关闭后无法再次查看”。 |
| 落点 | 关闭抽屉，列表中新行高亮 2 秒，显示同步状态。 |
| 异常 | 地址冲突 → 字段错误 + 建议地址；保存失败 → 抽屉底部红色横幅，保留输入；生效失败 → 行显示“生效失败 · 重试”。 |
| 审计 | `peer.created` |

## F4 管理客户端

| 操作 | 位置 | 级别 | 交互 |
|---|---|---|---|
| 编辑 | 行点击 → 抽屉 | — | 同 F3 表单，未修改时主按钮禁用 |
| 停用 / 启用 | 行 ⋯ 菜单 | L1 | 立即执行 + Toast“已停用 ipad · 撤销” |
| 重新生成密钥 | 行 ⋯ 菜单 | L2 | 确认框：“旧配置将立即失效，ipad 需要重新导入” → 抽屉打开结果视图 |
| 删除 | 行 ⋯ 菜单最底部 | L2 | 确认框：“删除客户端 ipad？它会立即断开” |
| 批量停用 / 删除 | 勾选后批量条 | 取最高级别 | 确认框列出数量与前 5 个名称 |

## F5 安装应用（节点层，抽屉多步）

| 步骤 | 规定 |
|---|---|
| 入口 | 唯一：`/hubs/:id/apps` 页头「安装应用」。 |
| 1 选择 | 抽屉内显示签名目录卡片（图标、名称、一句话、版本）；已安装的显示“已安装”且不可选；不兼容本节点架构的显示原因且不可选。 |
| 2 预检 | 节点实时上报，逐项显示：架构、内存、端口、依赖证书、与已安装应用冲突。三种结果：✓ 通过（绿）、⚠ 警告（琥珀，可继续）、✕ 阻断（红，「下一步」禁用，并给出解决入口链接）。底部说明“无阻断项，可继续”或“有 1 个阻断项”。下方“安装后将会”列出对节点的全部改动（开端口、建服务、订阅证书）。 |
| 3 配置 | 由应用 Schema 生成（见 4.25 映射表）。只展示必填与推荐字段，其余在“高级”。 |
| 4 安装 | 主按钮「安装」→ 抽屉切换为任务视图（步骤 + 实时日志），底部「在后台运行」。 |
| 落点 | 成功 → 跳转 `/hubs/:id/apps/:app`（概况 Tab），Toast（若在后台）“Hysteria2 已安装 · 查看”。失败 → 留在任务视图，显示失败步骤与「重试」「查看日志」；节点上自动回滚（后端保证），文案说明“已回滚，节点未改变”。 |
| 审计 | `app.installed` / `app.install_failed` |

## F6 配置、重启、升级、卸载应用

| 操作 | 位置 | 级别 |
|---|---|---|
| 修改配置 | 应用详情「配置」Tab（T4），底部保存条 | 字段带 `x-danger: restart` 时保存为 L2，否则无确认 |
| 重启 | 页头「重启」 | L2（写明中断约 1 秒） |
| 升级 | 概况 Tab 出现“有新版本 2.6.1”卡片 → 「升级」 | L2，任务抽屉 |
| 卸载 | 「配置」Tab 最底部危险区 | L3，输入应用名；可勾选“同时删除数据”（默认不勾） |

## F7 添加站点（节点层，抽屉）

- 入口唯一：`/hubs/:id/sites` 页头「添加站点」。
- 字段：域名 → 失焦后实时检查 DNS 是否解析到本节点（✓ 已指向 203.0.113.10 / ⚠ 指向其他地址 / ⚠ 未解析）；上游（类型：WireGuard 客户端下拉 / 本机端口 / 自定义地址）；高级：访问限制、请求头。
- ⚠ 不阻断保存，但说明“解析生效前，Caddy 无法签发证书”。
- 审计 `site.created`。

## F8 签发证书（节点层，抽屉）

- 入口唯一：`/hubs/:id/certs` 页头「签发证书」。
- 字段：域名（支持通配符）、验证方式（DNS-01 / HTTP-01，选通配符时自动锁定 DNS-01 并说明原因）、DNS 凭据（下拉，引用全局资源，旁边“管理凭据”，遵守 S9）、使用者（可选，勾选本节点上的应用）。
- 主按钮「签发」→ 任务抽屉。
- 续期失败：证书页顶部琥珀横幅 + 概览“需要处理”；横幅按钮直达修复点（通常是凭据）。

## F9 节点离线与恢复

- 离线 90 秒内：不提示（避免抖动）。
- 90 秒–10 分钟：节点徽章“离线 N 分钟”，节点层顶部灰色横幅。
- 超过 10 分钟：进入概览“需要处理”。
- 恢复连接：横幅消失，期间保存的改动自动生效，“待上线后生效”变为“下发中”再到“已同步”。不弹 Toast。

## F10 升级 Agent / 重新接入 / 删除节点（节点设置）

| 操作 | 位置 | 级别 | 说明 |
|---|---|---|---|
| 升级 Agent | 节点设置 · “Agent”分区；节点概况也可出现“有新版本”卡片 | L2 | 任务抽屉；失败自动回滚旧版本 |
| 重新接入（服务器重装） | 节点设置 · 危险区 | L2 | 生成新安装命令，保留全部配置；旧凭据立即作废 |
| 删除节点 | 节点设置 · 危险区最底部 | L3 | 文案列出子对象数量（S11）；输入节点名确认；删除后回到 `/hubs` 并 Toast（不可撤销，不带撤销按钮） |

## F11 全局资源（设置）

- DNS 凭据：列表 + 抽屉添加。字段：服务商、名称、Token（只写不读）。保存时后端立即做一次只读校验，结果显示在行内（✓ 可用 / ✕ 403）。

# 4. 组件详规

每个组件条目包含：**用途 · 不用于 · 结构 · 尺寸 · 变体 · 状态 · 参数（TypeScript）· 文案 · 行为 · 无障碍 · 禁止**。参数接口即白名单：组件**不接受** `className`、`style`、任意 HTML 属性透传（`aria-*` 与 `data-testid` 除外）。

## 4.1 Button 按钮

- **用途**：触发一个动作。
- **不用于**：跳转页面（用 Link）；切换状态（用 Toggle）；选项选择（用 Segmented）。
- **结构**：`[图标?] 文案` 或 `[旋转环] 进行时文案`。图标在左，间距 6。
- **尺寸**：md 高 32、左右内边距 12、字号 14/500；sm 高 26、内边距 8、字号 13；icon 方形 32（sm 26）。手机 md 高 40。最小宽度 64（icon 除外）。
- **变体**：

| variant | 底 / 边 / 字 | 允许出现的位置 |
|---|---|---|
| `primary` | accent-solid / 同 / 白 | 页头最右、抽屉底最右、对话框底最右、向导底最右、保存条最右。**每个区域最多 1 个** |
| `default` | surface / border / text | 任意 |
| `ghost` | 透明 / 透明 / text-2 | 表格行内、工具栏、抽屉头关闭按钮 |
| `danger` | danger-solid / 同 / 白 | **只**在 L2/L3 确认对话框底部 |
| `danger-text` | surface / border / danger | 危险区按钮、任务抽屉“取消任务” |

- **状态**：默认 / 悬停（底色变 surface-2 或 accent-solid-hover，120ms）/ 按下（下移 1px）/ 键盘焦点（`--focus` 外环 3px，只在键盘聚焦时）/ 加载（旋转环 + 进行时文案，宽度锁定为加载前宽度，禁止点击）/ 禁用（不透明度 0.45，不响应悬停，必须有原因提示；`disabledReason` 由外层包裹元素以 title 呈现，保证可悬停可读）。见附录 09 状态矩阵。
- **参数**：

```ts
interface ButtonProps {
  variant?: 'primary' | 'default' | 'ghost' | 'danger' | 'danger-text'; // 默认 default
  size?: 'md' | 'sm';                // 默认 md
  icon?: IconName;                   // 来自封闭图标集
  iconOnly?: boolean;                // 为 true 时 label 作为 aria-label
  label: string;                     // 必填，来自文案字典
  loadingLabel?: string;             // 加载时文案，如“保存中”
  loading?: boolean;
  disabled?: boolean;
  disabledReason?: string;           // disabled=true 时必填
  shortcut?: 'N' | 'Enter' | 'Esc';  // 仅登记过的快捷键
  onClick: () => void | Promise<void>; // 返回 Promise 时自动进入 loading
}
```

- **文案**：动词 + 对象，2–6 个汉字：`添加客户端`、`保存并生效`、`安装`、`签发`、`重试`。取消一律 `取消`；关闭结果视图一律 `完成`。**禁止**：确定、提交、OK、是、否、好的。
- **行为**：`onClick` 返回 Promise 时自动 loading，结束后恢复；双击只触发一次；加载超过 10 秒仍未返回，按钮旁显示“仍在处理…”。
- **无障碍**：原生 `<button>`；iconOnly 必须有 aria-label；loading 时 `aria-busy="true"`。
- **禁止**：同区域两个 primary；primary 与 danger 同时出现；按钮内换行；纯图标按钮用于除 ⋯、×、复制 以外的操作。

## 4.2 Link 链接

- **用途**：导航到另一个页面或打开抽屉。
- **样式**：accent 色，14px，无下划线，悬停下划线。表格中的对象名不用 Link 样式（整行可点）。
- **参数**：`{ to: RouteRef; label: string; external?: boolean }`。外链右侧自动加 ↗，新标签打开。
- **禁止**：用链接触发会改变数据的操作。

## 4.3 Badge 状态徽章

- **用途**：表达一个对象的当前状态。
- **结构**：`[6px 圆点?] 文字`，高 22，内边距 0 8，圆角 999，字号 12/500。
- **语气**：

| tone | 底 / 字 | 用于 |
|---|---|---|
| `ok` | ok-soft / ok | 在线、运行中（应用）、有效、已生效 |
| `warn` | warn-soft / warn | 降级连接、即将到期、需重启 |
| `danger` | danger-soft / danger | 失败、生效失败、已过期 |
| `info` | accent-soft / accent | 下发中、安装中、续期中、运行中（任务） |
| `neutral` | neutral-soft / text-2 | 离线、已停用、空闲、等待接入 |

- **参数**：`{ tone: Tone; label: string; dot?: boolean }`。
- **文案**：≤ 6 个汉字；离线必须带时长（`离线 2 小时`）。
- **禁止**：自定义颜色；用徽章做分类标签（分类用 Tag）；一个单元格放两个徽章。

## 4.4 StatusDot 状态点

- 8px 圆点（徽章内 6px），颜色同 Badge 语气。**必须**与文字或对象名相邻出现，不得单独表达状态。
- `pulse` 只用于 info（进行中），表现为 3px accent-soft 外环（静态，不做呼吸动画）。

## 4.5 SyncStatus 同步状态

本产品专有组件，所有“期望配置 vs 节点实际”的显示**必须**用它，不得自己拼。

| state | 外观 | 文案 | 可点击 |
|---|---|---|---|
| `synced` | ✓ 图标 + text-2 | 已同步 | 否 |
| `pending` | info 脉冲点 + accent | 下发中 · rev 42 | 否 |
| `queued` | ⏸ 图标 + warn | 待上线后生效 | 否（悬停说明节点离线时长） |
| `failed` | ⚠ 图标 + danger | 生效失败 · 重试 | 是：打开错误详情（错误摘要、节点日志片段、重试按钮） |

- **参数**：`{ state: SyncState; rev?: number; onRetry?: () => void }`，`failed` 时 `onRetry` 必填。
- **位置**：节点列表“配置”列、节点层页头副标题、被修改对象所在行的状态列。
- **行为**：状态由实时推送驱动，切换时无动画，只换内容；`aria-live="polite"`。

## 4.6 ScopeChip 作用域标签

- 高 22，内边距 0 8，圆角 4，surface-2 底，text-2 字，12/500，左侧 server 图标 12px，文字为节点名。
- **必须**出现在每个节点层页面页头副标题的第一个位置。点击打开节点切换下拉。

## 4.7 Tag 标签

- 高 20，内边距 0 6，1px border，圆角 4，11px，text-2。用于用户自定义分类（设备类型、自定义标签）。最多显示 2 个，超出显示 `+N`。

## 4.8 Sidebar 侧栏

- **全局侧栏**：品牌（22px 方标 + 名称，600）→ 导航 4 项（概览、节点、活动、设置）→ 分组标题“节点” → 节点快捷列表（状态点 + 名称，行高 30，最多 12 个，超出显示“全部 N 个 →”）→ 底部控制面状态。
- **节点侧栏**：“← 全部节点”（行高 30，text-3）→ 节点切换卡（1px border、圆角 8、bg 底：状态点 + 名称 600 + 地区·状态 12px + 上下箭头）→ 导航 6 项（概况、WireGuard、站点、转发、证书、应用，右侧计数 12px text-3）→ 分隔线 → 活动、节点设置 → 底部控制面状态。
- **导航项**：高 34，内边距 0 12，圆角 6，图标 16 + 间距 12；默认 text-2；悬停 surface-2 底 + text；当前 surface-2 底 + text + 500。
- **禁止**：在侧栏放按钮（除切换卡外）；新增导航项而不更新 1.3 路由总表。

## 4.9 Topbar 顶栏

- 高 52，surface 底，下边框。左：面包屑；右：全局搜索框（宽 260，⌘K 提示）+ 主题切换（ghost icon）。后台任务运行时在搜索框左侧出现任务胶囊（info 徽章样式：“1 个任务运行中”）。
- **禁止**：在顶栏放页面操作按钮。

## 4.10 Breadcrumb 面包屑

- 14px，text-2，分隔为 right 图标 14px，最后一级 text + 500。最多 4 级。每一级（除最后）可点击。节点层格式固定为 `节点 › {节点名} › {页面名}[ › {对象名}]`。

## 4.11 PageHeader 页头

- **结构**：左：h1（20/600）+ 副标题行（13px text-2，元素间距 12：ScopeChip → 摘要 → SyncStatus）；右：操作区（间距 8，从左到右：次要按钮 → ⋯ → 主按钮）。下边距 24。
- **参数**：

```ts
interface PageHeaderProps {
  title: string;
  scope?: HubRef;              // 节点层页面必填
  summary?: string;            // 一句话，≤ 30 字
  sync?: SyncStatusProps;
  primaryAction?: ActionRef;   // 来自动作注册表（7.4），不是任意按钮
  secondaryActions?: ActionRef[]; // ≤ 2 个，其余进 moreActions
  moreActions?: ActionRef[];
}
```

- **禁止**：标题旁放图标以外的装饰；副标题超过一行；主操作不在动作注册表中。

## 4.12 Tabs 标签页

- 只用于 T3 对象详情。高度由内容决定，项间距 20，底部 2px 指示条（text 色），当前项 text + 500，其他 text-2；计数 11px text-3。
- Tab ≤ 5；没有内容的 Tab 仍显示（计数 0）；Tab 状态写入 URL。
- **长文本**：每个 Tab 标签最大宽 160px，超出按 4.27 截断（域名用中间截断），悬停显示全文；Tab 标签只能是固定文案或对象名，**不得**把用户数据（域名、路径）直接拼成 Tab 名，需要区分多个同类对象时用 Select 切换，而不是一排 Tab。
- **禁止**：在 Tab 内再放 Tab；用 Tabs 做筛选（用 FilterChip 或 Segmented）；Tab 数量随数据增长（Tab 必须是设计时固定的）。

## 4.13 Card 卡片 与 Stat 统计

- Card：surface 底、1px border、圆角 12、无阴影。可选头部（12/16 内边距、下边框、标题 14/500、右侧“全部 →”链接 13px）。内容区内边距 16（表格卡片为 0）。
- Stat：内边距 16；标签行（13px text-2 + 16px 图标）→ 数值（24/600，tabular-nums，可带 14px text-3 单位或分母）→ 提示（12px text-3，一行，可为空）。统计条最多 4 张，等宽。
- **禁止**：卡片嵌卡片（列表卡片中的子列表用 list-row）；统计卡放按钮。

## 4.13a Split 分栏

- **用途**：主内容 + 右侧辅助栏（如 T1 概览：左侧列表 2fr、右侧「需要处理/最近活动」1fr）。
- **尺寸**：桌面 `2fr / 1fr`，间距 16；<1024 自动堆叠为单列（主内容在上）。
- **参数**：`{ main: ReactNode; aside: ReactNode; gap?: Gap }`。
- **禁止**：左右两栏都放表格；aside 里再套卡片网格。

## 4.14 Table 表格

**结构**：Card → Toolbar（可选）→ `<table>`。

| 部分 | 规定 |
|---|---|
| Toolbar | 内边距 12/16，下边框。从左到右：搜索框（宽 220，高 28，占位“筛选{对象}”）→ 筛选片（FilterChip）→ 右侧留空。**主操作不放工具栏，放页头**。 |
| 表头 | 高 36，12px/500 text-3，左对齐，不加粗、不排序图标常显（可排序列悬停时显示 ↕） |
| 行 | 高 44，下边框，最后一行无边框；悬停 surface-2；当前在抽屉中打开的行 accent-soft |
| 第一列 | 对象名（500）+ 左侧状态点 + 可选 Tag；停用对象整行文字 text-3 |
| 最后一列 | 行操作：ghost icon sm `⋯`，右对齐；宽 48 |
| 技术值 | 等宽 12.5px |
| 空值 | `—`（text-3） |
| 数值 | tabular-nums，同一表内对齐方式一致 |

- **列顺序**：名称 → 状态 → 关键属性（地址/域名/版本）→ 数值（流量/客户端数）→ 时间 → SyncStatus → ⋯。
- **排序**：默认“需要关注优先”（失败 > 离线 > 降级 > 正常 > 停用），其次名称升序。用户点击表头可切换，写入 URL。
- **行点击**：打开该对象详情（抽屉或页面）；行内按钮点击不触发行点击。
- **加载**：首次加载显示 5 行骨架；刷新时保留旧数据。
- **空**：表格区域显示 EmptyState（不是空表头）。筛选后无结果显示一行“没有匹配的{对象}”+「清除筛选」。
- **批量**：仅登记了批量动作的表格显示复选框列（宽 40）。勾选后 Toolbar 替换为批量条：`已选 3 项 · [停用] [删除] · 取消选择`。
- **分页**：超过 50 行才出现，底部右侧“1–50 / 128  ‹ ›”。
- **参数**：

```ts
interface TableProps<T> {
  rows: T[] | undefined;                 // undefined = 加载中
  columns: ColumnDef<T>[];               // 列类型封闭：'name'|'status'|'mono'|'number'|'time'|'sync'|'text'|'actions'
  rowKey: (r: T) => string;
  onRowOpen?: (r: T) => void;
  openRowKey?: string;                   // 当前抽屉中打开的行
  rowActions?: (r: T) => ActionRef[];    // 渲染进 ⋯ 菜单
  bulkActions?: ActionRef[];
  empty: EmptyStateProps;
  search?: { placeholder: string };
  filters?: FilterDef[];
}
```

- **高度锁定**：行高是 `height: 44px`，不是最小高度；所有单元格单行（`white-space: nowrap`），永不换行、永不撑高。表格卡片高度 = 表头 + 行数 × 44 + 工具栏，不设固定容器高、不出现内部滚动条。T1 概览里的表格最多 6 行，底部“全部 →”。
- **列宽**：由列类型决定，页面不得指定像素宽：

| 列类型 | 宽度 | 对齐 | 超长处理 |
|---|---|---|---|
| `name` | 弹性，最小 160，最大 320 | 左 | 末尾截断 |
| `status` | 内容宽，最大 140 | 左 | 徽章文案本身 ≤ 6 字 |
| `mono`（IP、端口、域名、指纹） | 弹性，最小 120，最大 280 | 左 | 域名/指纹中间截断，IP/端口不截断 |
| `number` | 固定 88 | 右 | — |
| `time` | 固定 112 | 左 | 相对时间（5.8） |
| `sync` | 固定 160 | 左 | — |
| `text` | 弹性，最大 240 | 左 | 末尾截断 |
| `actions` | 固定 48 | 右 | — |

- **列数上限**：桌面 ≤ 7 列（不含勾选与操作列）；平板自动隐藏标记为 `priority: 'low'` 的列；放不下就删列，不横向滚动。
- **列清单固定**：每个列表页的列在 UI 变更单里定死，同一对象在不同页面出现时列顺序一致。
- **禁止**：自定义单元格渲染（只能用封闭列类型）；行内超过 1 个可见按钮；表格横向滚动（列放不下就删列，次要信息进详情）；斑马纹。

## 4.15 FilterChip 筛选片 / SearchInput 搜索框

- FilterChip：高 28，圆角 999，13px。未启用为 1px 虚线 border-strong + text-2（文案“+ 标签”）；启用为实线 + surface-2 底 + text（文案“状态：在线 ×”）。点击打开下拉多选。
- SearchInput：高 28，圆角 6，左 14px 搜索图标，输入即过滤（去抖 150ms），Esc 清空。快捷键 `/` 聚焦。

## 4.16 Field 字段容器

- **结构**（纵向，间距 6）：Label（13/500）→ 控件 → 帮助文字或错误（12px，二选一，错误优先）。字段间距 16。
- **行式字段**（开关、短数值）：左侧标题（14）+ 说明（12 text-3），右侧控件；上边框分隔，内边距 12/0。
- **参数**：`{ label: string; optional?: boolean; help?: string; error?: string; children }`。`optional` 时标签后加“（可选）”（text-3）。
- **文案**：Label 用名词，不加冒号；help 写“为什么/怎么填”，≤ 40 字；error 用“发生了什么 + 怎么办”。
- **禁止**：红色星号；占位符代替标签；帮助与错误同时显示。

## 4.17 TextInput / NumberInput / PortInput

| 项 | 规定 |
|---|---|
| 尺寸 | 高 32（手机 40），内边距 0 10，圆角 6，1px border-strong，surface 底，14px（手机 16） |
| 状态 | 默认 / 聚焦（accent 边 + `--focus` 外环）/ 错误（danger 边，聚焦时仍是 danger 边 + focus 外环）/ 校验中（右侧 12px 旋转环）/ 只读（surface-2 底，text-2，可选中复制）/ 禁用（只读样式 + 0.5 不透明度，必须有原因） |
| 后缀 | 右侧 text-3：单位（秒、MB）、“自动”、状态图标 |
| 等宽 | `mono` 用于 IP、CIDR、端口、域名、UUID |
| NumberInput | 只允许数字，失焦时夹到 min/max 并提示；不显示上下箭头 |
| PortInput | 数字 1–65535 + 协议后缀（/tcp /udp）；失焦 300ms 后向节点查询占用，冲突时错误文案必须包含占用者和替代建议 |
| 参数 | `{ value; onChange; mono?; suffix?; placeholder?; readOnly?; disabled?; disabledReason?; validate?: Validator; asyncValidate?: AsyncValidator; autoFilled?: boolean }` |
| 校验时机 | 失焦：格式校验 + 异步校验；输入中：只清除旧错误不报新错误；提交：全量校验，滚动并聚焦第一个错误 |
| 禁止 | 输入框内放按钮（复制除外）；用 placeholder 写说明；自动修正用户输入而不提示 |

## 4.18 Select / Segmented / Toggle / Checkbox

| 组件 | 何时用 | 尺寸与样式 | 规则 |
|---|---|---|---|
| Segmented | 2–4 个互斥选项，且选项名短 | 高 32（内段 26），surface-2 底，当前段 surface 底 + 轻阴影 + 500 | 选项 ≤ 4，每项 ≤ 8 字 |
| Select | 5 个以上选项，或选项需要附加信息（证书到期天数、凭据状态） | 外观同 TextInput，右侧下箭头；下拉为 Menu 样式，选项可带一行说明 | 超过 10 项自动带搜索 |
| Toggle | 二元设置 | 34×20，开启 accent-solid，关闭 border-strong；放在行式字段右侧 | 在表单中只改变表单值，随保存提交；**独立的立即生效开关只允许出现在列表行**（如启停），且属于 L1 |
| Checkbox | 多选、表格勾选、确认勾选（“同时删除数据”） | 16×16，圆角 4 | 不用于单个二元设置（用 Toggle） |

**禁止**：单选按钮组（Radio）——用 Segmented 或 Select 替代。

## 4.19 SecretField 机密字段

| kind | 用于 | 外观 | 行为 |
|---|---|---|---|
| `stored` | 控制面保存的凭据（DNS Token） | 未设置：普通密码输入；已设置：只读条 `已设置 · ••••3f9a` + ghost「替换」 | 点「替换」变为空输入框 + 「取消」；永不回显明文 |
| `once` | 新生成、只显示一次的内容（客户端配置） | 二维码 / 下载 / 复制 三按钮 + 琥珀提示“只显示这一次” | 关闭前若未下载或复制，L2 确认 |
| `agent` | 节点本地生成并持有的密钥（Reality 私钥） | surface-2 只读条：盾牌图标 + “私钥由节点生成，不离开 hk-1” + 右侧“公钥 Zq3x…Lm8A”+ 复制 | 无编辑；可在 ⋯ 中“在节点上重新生成”（L2） |

- 指纹/公钥显示首 4 + 尾 4，中间 `…`。复制按钮点击后图标变 ✓ 1.5 秒，并朗读“已复制”。
- **禁止**：任何地方显示节点 token、Service Token、私钥明文；把机密放进 URL、Toast、日志。

## 4.20 KeyValue 键值列表 / CodeBlock 代码块

- KeyValue：两列，键 13px text-2（宽 120），值 14px text（技术值等宽），行高 32，用于概况卡片。值可带复制按钮。
- CodeBlock：surface-2 底、1px border、圆角 8、内边距 12/16、等宽 12.5px、自动换行（不横向滚动），右上角「复制」按钮（sm default）。用于安装命令、配置预览。

## 4.21 Drawer 抽屉

- **尺寸**：右侧，宽 480（手机全屏），高 100%，surface 底，左边框 + 浮层阴影；遮罩 `--scrim`。
- **结构**：头（内边距 16/20，下边框：标题 16/600 + 副文本 12px text-3 写节点名与上下文 + 右侧 × ghost icon）→ 体（内边距 20，可滚动）→ 底（内边距 12/20，上边框：左侧后果说明 12px text-3，右侧“取消”+ 主按钮）。
- **视图**：一个抽屉可以有多个视图（表单 → 结果；步骤 1 → 2 → 3；表单 → 任务），切换时头部标题不变、副文本可变，底部按钮随视图变化。
- **参数**：`{ title; context: string; views; onClose; dirty?: boolean }`。
- **行为**：打开时焦点移到第一个可编辑字段；Esc 或点遮罩关闭（dirty 时拦截“放弃修改？”）；URL 同步；返回键关闭。
- **禁止**：抽屉里开抽屉；抽屉里放 Tabs；一个抽屉处理两个对象；底部超过 2 个按钮（多步视图可有“上一步”，共 3 个）。

## 4.22 Dialog 对话框 / ConfirmDialog 确认

- **尺寸**：宽 420，居中，圆角 12，浮层阴影。体内边距 20；底部内边距 12/20，上边框，按钮右对齐。
- **ConfirmDialog 是唯一允许的对话框用途**（除命令面板外）。

| level | 标题 | 正文 | 确认按钮 | 额外 |
|---|---|---|---|---|
| L2 | 问题句：“重启 sing-box？” | 影响范围 + 时长 + 是否可恢复，≤ 60 字 | `danger`（会中断/删除时）或 `primary`（只是需要知情） | — |
| L3 | 问题句：“删除节点 fra-1？” | 删除内容清单（S11）+ “此操作不可恢复” | `danger`，默认禁用 | 输入框：“输入 fra-1 确认”，完全匹配后启用 |

- **参数**：`{ level: 'L2'|'L3'; title; body; confirmLabel; confirmName?: string /* L3 必填 */; onConfirm: () => Promise<void> }`。
- **行为**：打开时焦点在“取消”（L2）或确认输入框（L3）；Enter 不能直接确认 L3；确认后按钮 loading，失败时在对话框内显示错误而不关闭。
- **禁止**：在对话框里放表单（L3 输入框除外）；对话框标题用“提示”“警告”“确认”；“取消”以外的第三个按钮。

## 4.23 Menu 菜单（⋯）

- 宽 200，内边距 4，圆角 8，浮层阴影；项高 32，内边距 0 8，圆角 4，图标 14 + 间距 8。
- **顺序**：查看类 → 修改类 → 状态切换类 → 分隔线 → 危险类（danger 文字，永远在最底部）。
- 禁用项保留显示并在悬停时说明原因。
- **禁止**：菜单里放主操作；嵌套子菜单。

## 4.24 Toast / Banner / InlineError

| 组件 | 规定 |
|---|---|
| Toast | 底部居中，距底 24；反色（text 底、bg 字），圆角 8，内边距 10/12/10/16，14px；可带一个文字按钮（撤销 / 查看）；4 秒后消失（悬停暂停）；同时最多 1 个，新的替换旧的。只用于：L1 撤销、后台任务结束。 |
| Banner | 圆角 8，内边距 12/16，13px；左图标 16；标题行 + 可选说明行（text-2）；右侧可选一个 sm 按钮。tone：warn（未保存、即将到期、降级）/ danger（失败）/ info（说明性）/ neutral（离线）。位置：所描述范围的顶部；同一范围 ≤ 2 条，按严重程度排序。 |
| InlineError | 字段下 12px danger 文字；表单整体错误放抽屉底部上方的 danger Banner。 |

**禁止**：用 Toast 报错；成功时同时出 Toast 和 Banner；Banner 自动消失。

## 4.25 Schema 控件（应用配置）

应用配置由 Schema 渲染，插件**只能**使用下表控件：

| Schema / widget | 渲染为 |
|---|---|
| `string` | TextInput |
| `string` + `format: hostname / ipv4 / cidr / uri` | TextInput mono + 格式校验 |
| `string` + `enum`（≤4 / >4） | Segmented / Select |
| `integer` | NumberInput（min/max 来自 Schema） |
| `integer` + `widget: port` | PortInput（含占用检查） |
| `boolean` | 行式 Toggle |
| `array<object>` | 卡片内 list-row 列表；末行“+ 添加{itemLabel}”；每行 ⋯（编辑、删除） |
| `array<enum>` | 多选 Tag 输入 |
| `x-secret: stored / agent` | SecretField 对应 kind |
| `widget: uuid / randomString` | TextInput mono + 后缀「生成」 |
| `widget: certPicker` | Select，选项显示到期天数，引用本节点证书 |
| `x-danger: restart` + `x-danger-note` | 保存时触发 L2，正文取 note |
| `ui.groups` | T4 左侧分区导航 |
| `ui.advanced: [field]` | 折叠进“高级”分区 |

插件提供的所有字符串按纯文本渲染；不能指定颜色、图标（只能从封闭集选）、布局、自定义组件。

## 4.25a 表单字段类型（控件由类型决定，不由开发者挑）

**所有表单**（内置的客户端、站点表单也一样）都用字段描述生成，开发者只声明“这是什么数据”，控件由下表唯一决定。这样同一种数据在全站永远是同一种控件。

| 数据类型（FieldType） | 控件 | 判定依据 |
|---|---|---|
| `text` / `name` | TextInput | 自由文本 |
| `host` / `ip` / `cidr` / `url` | TextInput mono + 格式校验 | 技术值 |
| `int`（带 unit） | NumberInput + 单位后缀 | 数值 |
| `port` | PortInput（含占用检查） | 端口 |
| `bool` | 行式 Toggle | 二元 |
| `choice`，选项 2–4 个且每项 ≤ 8 字，无附加信息 | Segmented | 少量互斥 |
| `choice`，选项 ≥ 5 个，或任一项 > 8 字，或需要附加说明 | Select | 多选项 |
| `ref`（引用另一个对象：证书、凭据、客户端） | Select（带状态说明，如“12 天后到期”） | 永远是 Select，哪怕只有 2 个 |
| `multi`（多选枚举） | Tag 多选输入 | 多选 |
| `list<object>` | list-row 列表 + “+ 添加” | 结构化列表 |
| `secret` | SecretField | 机密 |
| `generated`（UUID、随机串） | TextInput mono + 「生成」 | 可生成值 |

- 判定是机械的：`ui/form/pickControl.ts` 是唯一实现；页面**不得**直接使用 Segmented、Select、Toggle 组件，只能用 `<Form fields>`。
- **字段数量预算**：抽屉默认可见字段 ≤ 6，“高级”内 ≤ 8；T4 每个分区 ≤ 10。超出说明暴露过多（见 7.7）。
- **字段顺序**：必填 → 常改 → 少改；“高级”永远折叠在最后。

## 4.26 EmptyState / Skeleton / LogViewer / Steps / Stepper / CommandPalette

| 组件 | 规定 |
|---|---|
| EmptyState | 居中，上下内边距 48；40×40 圆角 10 surface-2 图标框（20px 图标）→ 标题 16/600（“现在是什么情况”）→ 说明 13px text-2（“为什么要做”，≤ 30 字）→ 一个 primary 按钮（必须是该页面页头的同一个主操作）。无插画。 |
| Skeleton | surface-2 → surface-3 渐变块，高 10，圆角 4；行数与真实布局一致；300ms 内返回不显示。 |
| LogViewer | surface-2 底、1px border、圆角 8、内边距 12、等宽 12px 行高 1.7；每行：时间戳（text-3，HH:MM:SS）+ 内容；INFO text-2 / WARN warn / ERROR danger / 成功 ok；自动滚到底，用户上滚则暂停并显示浮动“回到最新”；顶部右侧「复制」「下载」；最多保留 5000 行，更早的折叠为“显示更早的 N 行”。 |
| Steps（任务步骤） | 每行：18px 圆形图标（完成 ok 实心 + ✓ / 进行中 accent 旋转环 / 未开始 border-strong 空心 / 失败 danger 实心 + ×）+ 13px 文字 + 右侧耗时 12px text-3。 |
| Stepper（向导/多步抽屉步骤条） | 等分横条，每段上方 3px 线：完成 text-2 / 当前 accent-solid / 未到 border；下方 13px 步骤名。不可点击跳步（只能用上一步）。 |
| CommandPalette | ⌘K 打开，居中宽 560，顶部输入框 16px，结果按“节点 / 客户端 / 站点 / 应用 / 动作”分组，每组 ≤ 5；上下键选择，Enter 执行；动作结果必须显示其作用域（“添加客户端 · tyo-1”）。 |

## 4.27 Truncate 长文本截断

所有用户数据（名称、域名、路径、指纹、备注）**必须**通过 Truncate 渲染，任何容器都不允许被用户数据撑开。

| mode | 用于 | 示例 |
|---|---|---|
| `end` | 对象名、备注、说明 | `office-router-backup-…` |
| `middle` | 域名、URL、路径、密钥指纹 | `very-long-subdomain…example.dev` 保留末尾 12 字符 |
| `none` | IP、端口、CIDR、版本号（长度有上限，不截断） | `10.8.0.12` |

- 截断后悬停 300ms 显示 Tooltip 全文；键盘聚焦同样显示；复制操作永远复制全文。
- 默认最大宽度由所在位置决定：表格单元格 = 列宽；Tab 160；面包屑每级 200；页面标题与抽屉标题 = 容器宽度（单行）；侧栏 = 侧栏宽；Badge 不承载用户数据。
- **禁止**：`word-break: break-all` 用于用户数据（CodeBlock 除外）；多行省略；用 `title` 属性代替 Tooltip。

## 4.28 图标与符号纪律

- 界面中的所有图形符号只有一个来源：`ui/icons.ts` 的线性图标集（3.4）。
- **禁止 Emoji**：文案字典、JSX 文本、插件 Schema 字符串中出现任何 Emoji（含 ✅ ⚠️ 🔒 🚀 等）一律不允许。插件字符串中的 Emoji 在渲染前被剔除。
- **禁止**内联 `<svg>`、图片图标、图标字体、字符画（如用 “●” “✓” 字符代替图标）；状态点用 StatusDot 组件。
- 图标颜色只能继承文字颜色（`currentColor`），不得单独上色；彩色只出现在 StatusDot 和 Badge。

# 5. 交互模式

## 5.1 保存即生效

```
点“保存并生效” → 按钮 loading（“保存中”）
  → 写入成功（rev N）→ 抽屉关闭或切到结果视图；行高亮 2 秒
  → SyncStatus：下发中 · rev N
       ├─ 节点回执成功 → 已同步（不弹 Toast）
       ├─ 节点离线     → 待上线后生效
       └─ 节点回执失败 → 生效失败 · 重试 + 节点层顶部 danger 横幅（“已保留旧配置，服务未中断”）
```

- 改动影响节点时主按钮为「保存并生效」；只改控制面数据（备注、标签）时为「保存」。
- 保存前，抽屉/保存条左侧**必须**写一句后果：`保存后约 2 秒生效` / `sing-box 将重启（约 1 秒中断）` / `tyo-1 离线，上线后生效`。
- 后果包含“中断”的，保存时走 L2 确认。

## 5.2 创建/编辑形式选择

| 情况 | 形式 |
|---|---|
| 字段 ≤ 12，一屏能完成 | 抽屉 |
| 有前后依赖的多步（预检 → 配置 → 安装） | 多视图抽屉 |
| 跨越“对象尚不存在 → 外部操作 → 回到面板”的长流程（添加节点） | T5 向导页 |
| 分区多、字段多的持续配置（应用配置、设置） | T4 配置页 |
| 单字段（重命名、备注） | 行内编辑：点击文字 → 输入框，Enter 保存，Esc 取消 |

编辑与查看共用同一抽屉，打开即可编辑；未修改时主按钮禁用（disabledReason：“没有修改”）。

## 5.3 脏状态

- 抽屉：有修改时关闭/Esc/点遮罩 → “放弃修改？”（L2 样式，确认按钮 `放弃修改`，default 变体）。
- T4 页：顶部琥珀横幅“有 N 处未保存的修改”+ 底部保存条“放弃修改”可用；离开页面、切 Tab、切节点均拦截。
- 保存失败保留输入，错误标到字段。

## 5.4 危险操作分级

| 级别 | 判定（按后果，不按名称） | 交互 |
|---|---|---|
| L1 | 不影响在线连接，或 10 秒内可完全恢复 | 直接执行 + Toast 撤销 |
| L2 | 会中断在用的连接/服务，或使旧配置失效，但对象仍在 | ConfirmDialog L2 |
| L3 | 删除对象或数据，无法恢复 | ConfirmDialog L3（输入名称） |

动作注册表中每个动作**必须**声明级别（7.4），组件根据级别自动选择交互，页面不得自己决定。

## 5.5 长任务

- 节点上执行、可能超过 2 秒的操作都是任务：立即打开任务视图（任务抽屉，或流程抽屉切到任务视图）。
- 任务视图：标题（动作 + 对象）、元信息（编号 · 节点 · 发起时间）、Steps、LogViewer；底部「在后台运行」+「取消任务」（danger-text，L2）。
- 后台运行：顶栏任务胶囊；结束后 Toast“续期完成 · 查看”；失败则对象显示失败状态并进入概览“需要处理”。
- 同节点任务串行；排队时显示“排队中（前面 1 个）”。
- 实时通道断开：日志顶部显示 neutral 横幅“实时连接中断，正在每 5 秒刷新”，恢复后自动消失并补齐日志。

## 5.6 反馈选择

| 情况 | 方式 |
|---|---|
| 字段问题 | InlineError |
| 持续状况（失败、未保存、降级、离线、即将到期） | Banner |
| 完成且可撤销 | Toast + 撤销 |
| 完成，用户就在原地 | 不提示，状态自己变化 |
| 后台任务结束 | Toast + 查看 |
| 需要决定 | ConfirmDialog |

## 5.7 加载、空、错误、权限、冲突

| 情况 | 表现 |
|---|---|
| 首次加载 | Skeleton（300ms 后才出现） |
| 刷新 | 保留旧数据，页头右侧 14px 旋转环 |
| 空 | EmptyState，主按钮 = 页头主操作 |
| 页面加载失败 | 保留外壳；内容区：标题“无法加载 {页面}”+ 原因一句 + 「重试」+ 错误编号（可复制） |
| 版本冲突（别处已修改，rev 不一致） | 保存时抽屉底部 danger 横幅“这个客户端在 21:58 被修改过”+「查看差异」「覆盖保存」（L2）「放弃我的修改」 |
| 登录过期（Access） | 全屏遮罩“登录已过期”+「重新登录」，回来后恢复当前 URL 与未保存表单 |

## 5.8 时间、数字、单位

- 相对时间：<60 秒“42 秒前”，<24 小时“3 分钟前 / 2 小时前”，更早 `10-24 21:58`，跨年 `2025-12-30 21:58`。悬停显示完整时间 + 时区。日志、任务、审计一律绝对时间。
- 到期：剩余天数；≤14 天 warn，≤3 天 danger。
- 流量：KB/MB/GB，1 位小数，数字与单位间空格。端口 `51820/udp`。

## 5.9 键盘

`⌘K` 命令面板 · `/` 聚焦列表搜索 · `N` 当前页主操作 · `Esc` 关闭浮层 · `G` 然后 `O/N/A/S` 跳概览/节点/活动/设置 · 节点层 `G` 然后 `W/S/F/C/P` 跳 WireGuard/站点/转发/证书/应用。新增快捷键须登记于此。

# 6. 文案、响应式、无障碍

## 6.1 文案

- 语气平实直接；不用感叹号、“亲”“哦”“我们”；系统行为以“节点/面板”为主语。
- 问候只在概览页头（`下午好，康爷`）。
- 标题：页面用名词，抽屉用动作（`添加客户端`），对话框用问题句（`删除节点 fra-1？`）。
- 错误 = 发生了什么 + 怎么办；状态码与堆栈只放“详情”。
- 中英文/数字之间加空格；专名保持原样（WireGuard、Caddy、sing-box）。
- 所有文案放 `i18n/zh.ts` 字典，组件只接受字典键或字典值。
- **不加括号英文**：禁止“客户端（Peer）”“生效（Apply）”这类写法。英文只允许出现在专有名词白名单中：WireGuard、Caddy、sing-box、Hysteria2、Reality、Agent、DNS、IP、TCP、UDP、HTTP、HTTPS、ACME、DNS-01、HTTP-01、MTU、CIDR、UUID、Token、Cloudflare、Let's Encrypt。白名单外的英文词由 lint 拦截。
- **不出现后端术语**：rev 号只出现在 SyncStatus 里；不出现 desired/actual、reconcile、payload、schema、DO、KV、WS 等实现词。

**术语表**（界面只能用左列）：

| 用 | 禁止 |
|---|---|
| 节点 | Hub、主机、服务器（指对象时）、VPS、机器 |
| 客户端 | Peer、设备、用户（WireGuard 场景） |
| 站点 | 反代、网站、Caddy 站点 |
| 转发 | 端口映射、Forward |
| 应用 | 插件、模块、Module、服务（指对象时） |
| 生效 / 已同步 | 应用（动词）、Apply、部署 |
| 下发中 | 同步中、推送中 |
| 任务 | 作业、Job |
| 活动 | 审计、操作记录（“日志”只指运行日志） |
| 添加 / 安装 / 签发 | 新建、创建、新增（按钮上） |
| 取消 / 完成 | 确定、提交、OK、关闭（按钮上） |

## 6.2 响应式

- 手机必须完整支持：查看全部状态、F3 添加客户端并扫码、F4 停用/删除客户端、任务查看、处理“需要处理”。
- 手机降级：F1 添加节点（可看命令和进度，建议在电脑操作）、F5/F6 应用配置、批量操作——显示“这个操作在电脑上更方便”+「复制链接」。
- 变换规则：表格 → 列表行（名称 + 一行元信息 + 右侧状态，行高 ≥ 56）；抽屉 → 全屏页（多步）或底部弹层（结果视图）；页头操作 → 右上 ⋯，主操作 → 底部通栏按钮；全局底部标签栏 4 项（概览、节点、活动、设置）；节点层顶部为“← 节点名”+ 横向滚动的功能标签。
- 手机输入字号 16、控件高 40、点击区 ≥ 44×44。

## 6.3 无障碍

- WCAG AA 对比度；状态总有文字或图标。
- 浮层：打开时焦点移入并锁定，关闭后回到触发元素。
- 实时区域（SyncStatus、日志、任务胶囊）`aria-live="polite"`；错误 `role="alert"`；字段错误用 `aria-describedby` 关联。
- 尊重 `prefers-reduced-motion`、`prefers-color-scheme`（默认跟随系统，可手动切换并记住）。

# 7. Agent 执行约定

以下约定靠规范本身和 PR 评审执行，不额外引入 lint/测试/视觉回归门禁，避免拖慢发版。违反约定的 PR 在评审时退回。

## 7.1 工作协议：先交“UI 变更单”，获批再写代码

任何新增或修改界面的任务，Agent 必须先提交一份 UI 变更单（PR 描述或 `docs/ui-changes/NNN.md`），主人确认后才能写代码：

```
UI 变更单 #NNN
1. 作用域：全局 / 节点层；涉及对象及其父容器（对照 1.2 S12）
2. 流程：引用 F 编号；新流程按 F12 模板完整填写
3. 页面与模板：路由 + T1–T5
4. 入口：唯一创建入口位置（不得违反 S1–S3）
5. 动作清单：每个动作的 id、标签、级别 L1/L2/L3、是否任务、审计事件
6. 使用的组件：只能列第 4 章已有组件；需要新组件则附 4.x 格式的完整条目
7. 新文案：字典键与中文（对照术语表）
8. 状态覆盖：空 / 加载 / 错误 / 离线 / 同步四态 各自表现
9. 手机：完整支持 / 降级
10. 截图计划：浅色、深色、390 宽各一张
```

**未在变更单中出现的界面改动，一律视为越界，PR 退回。**

## 7.2 目录与依赖边界

```
web/src/
  styles/tokens.css        # 唯一令牌（从 design/ui/proto/tokens.css 同步，不得手改）
  ui/                      # 基础组件（第 4 章），唯一允许写 CSS 的目录
  patterns/                # SaveBar、TaskView、ConfirmDialog、SecretField、Wizard、ResultView
  registry/routes.ts       # 路由清单（7.4）
  registry/actions.ts      # 动作注册表（7.4）
  i18n/zh.ts               # 文案字典
  data/                    # query/command 层，唯一允许调用 API 的目录
  pages/                   # 只组合 ui + patterns + data，不写样式、不调 API
  apps/widgets/            # Schema 控件（4.25）
  dev/gallery/             # 组件状态样例页（开发自查与评审对照）
```

依赖方向：`pages → patterns → ui`，`pages → data`；`ui` 不得依赖 `data`、`pages`；`patterns` 不得依赖 `pages`。

## 7.3 编码约定

| 约定 | 防止什么 |
|---|---|
| `pages/`、`patterns/` 不写 `style`、`className`，不写 CSS | 页面自己写样式 |
| `pages/`、`patterns/` 不直接用原生 `button`、`input`、`select`、`table`、`dialog`、`a`、`svg`、`img`，只用 `ui/` 组件 | 绕过组件、自画图标 |
| `pages/` 不直接调 API，只通过 `data/` | 页面直连后端 |
| 文案只来自 `i18n/zh.ts`，符合 6.1 术语表与专名白名单，无 Emoji、无括号英文 | 文案各写各的、中英混杂 |
| `ui/` 的 CSS 只引用令牌变量，不写颜色字面量和魔法数字 | 新颜色、随意尺寸 |
| 表格、Tabs 的高度与滚动只在 `ui/table`、`ui/tabs` 内部定义 | 表格被撑高 |
| 表单只用 `<Form fields>`，不直接用 Segmented、Select、Toggle | 配置控件乱选 |

## 7.4 路由清单与动作注册表（集中登记）

路由和动作集中登记在两个文件里，页面只引用、不自定义。新增页面或动作先改这两个文件，评审时一眼就能看出有没有违反作用域规则。

```ts
// registry/routes.ts
export const routes = [
  { path: '/',                      scope: 'global', template: 'T1', title: 'nav.overview' },
  { path: '/hubs',                  scope: 'global', template: 'T2', title: 'nav.hubs', primary: 'hub.create' },
  { path: '/hubs/new',              scope: 'global', template: 'T5', title: 'hub.create' },
  { path: '/hubs/:hubId/wireguard', scope: 'hub',    template: 'T2', title: 'nav.wireguard', primary: 'peer.create' },
  // …
] as const;

// registry/actions.ts
export const actions = {
  'hub.create':   { object: 'hub',  kind: 'create', scope: 'global', entry: '/hubs', form: 'wizard', audit: 'hub.created' },
  'peer.create':  { object: 'peer', kind: 'create', scope: 'hub', parent: 'hub', entry: '/hubs/:hubId/wireguard', form: 'drawer', audit: 'peer.created' },
  'peer.disable': { object: 'peer', kind: 'update', scope: 'hub', level: 'L1', audit: 'peer.disabled' },
  'peer.delete':  { object: 'peer', kind: 'delete', scope: 'hub', level: 'L2', audit: 'peer.deleted' },
  'hub.delete':   { object: 'hub',  kind: 'delete', scope: 'global', level: 'L3', confirmName: 'hub.name', audit: 'hub.deleted' },
  // …
} as const;
```

登记时须满足：

1. 每类对象恰好一个 `kind: 'create'` 动作（S1）。
2. `scope: 'hub'` 的动作入口以 `/hubs/:hubId/` 开头；全局路由不引用节点层动作（S2、S10）。
3. 每条路由至多一个 `primary`，且该动作的入口就是这条路由。
4. 删除类动作必须声明 L2 或 L3；L3 必须有 `confirmName`。
5. 每个动作有审计事件名。

页面中的按钮、菜单项、批量操作只能通过 `ActionRef` 引用注册表中的动作（PageHeader、Table、Menu 的参数类型已限制），确认级别、文案、审计因此不会被页面绕过。这是类型约束，编译时即生效，不增加额外检查步骤。

## 7.7 功能暴露准入（防止把后端全堆上来）

后端有某个能力 ≠ 界面要有某个控件。每个后端能力在 UI 变更单的“能力暴露表”里必须归入以下四档之一：

| 档 | 判定 | 界面表现 |
|---|---|---|
| A 主路径 | 主人在常规流程里需要做的决定 | 默认可见字段 / 页头主操作 |
| B 偶尔调整 | 有合理默认值，少数情况需要改 | “高级”折叠区 |
| C 只看不改 | 有助于判断状态，但不需要人决定 | 详情抽屉的 KeyValue 或日志 |
| D 不暴露 | 实现细节、调试用、可自动决定的值 | 不出现在界面（必要时只在 API/CLI） |

- 默认归 D，要升档必须写出“主人在什么情况下需要它”。说不出具体情况的一律 D。
- 能自动探测或自动选择的值（公网 IP、隧道地址、MTU、端口建议）显示为“自动”并可覆盖，而不是要求填写。
- 同一个能力只在一个地方可改（与 S1 一致）。
