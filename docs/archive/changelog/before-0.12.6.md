## [0.12.5] - 2026-11-13

### Added

- 主机运维「系统服务」分段内新增「系统错误」折叠区，按需读取近 24 小时系统错误日志与 OOM 记录（Agent 0.1.45 / 面板 0.12.5）。

### Changed

- 进程列表 CPU% 改为同请求内两次采样求差（间隔 0.5 秒），显示瞬时占用（Agent 0.1.45）。

## [0.12.4] - 2026-11-13

### Added

- 主机诊断新增 7 类问题（磁盘/inode、内存、failed 单元、需重启、OOM、只读文件系统、内存压力），阈值集中在 Worker 侧，旧 Agent 自动跳过（Agent 0.1.44 / 面板 0.12.4）。

### Fixed

- 端口转发进入崩溃重启循环（如端口被占用）时按失败上报，诊断给出 `unit_failed`，不再显示「生效」（Agent 0.1.43）。
