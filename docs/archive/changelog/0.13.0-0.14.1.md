# Changelog Archive (`0.13.0` – `0.14.1`)

## [0.14.1] - 2026-11-16
### Fixed
- 主机运维页不再随机报「操作失败，请稍后重试」：只读查询（服务、进程、防火墙、公钥、定时任务）不再抢占节点写锁，打开页面或同时刷新多个区块时不会互相 409，只读请求也不再需要幂等键（需 Agent 0.3.1）。
- 真的撞上写锁冲突时，提示改为「节点正在执行另一个写操作，请稍后重试」，不再落到通用错误文案。

## [0.14.0] - 2026-11-16
### Changed
- 应用安装的运行身份改为「以 root 运行」或「新建应用用户」二选一，去掉默认用户 nobody；选 root 时安装抽屉显示警示，脚本在 Agent 沙箱外以 root 执行（需 Agent 0.3.0）。
- 每次应用脚本安装、卸载都写审计，记录应用、实例、版本与运行身份，不记密码。
- 卸载沿用安装时的运行身份，已建好的应用用户卸载时不再要求密码。
### Fixed
- 「新建应用用户」填 root、uid 为 0 的账号、已有的登录账号或管理员组成员时一律拒绝，不会再悄悄以 root 执行。

## [0.13.0] - 2026-11-15

### Added

- 面板「应用管理」入口：应用定义（适配脚本正文 + 元数据）存 D1，可在页面上新增、编辑、停用、删除，不必发新版 Agent 或重新构建面板。
- 应用目录改为运行时读取应用清单，删除构建期目录生成链路；以后添加脚本无需发版。
- 安装动作支持按应用 ID 从控制面下发脚本，节点校验 sha256 后以应用专属普通用户执行；新增、修改、删除定义均写入审计并记录脚本哈希变化。
- 安装时可选运行身份：使用默认用户（nobody，不建账号）或新建应用用户（填用户名和密码，节点自动建账号并设密码）。凭据不落 D1、不进审计与命令行，只经 stdin 传递给 chpasswd。
