# Changelog（0.12.6 – 0.12.10，归档）

> 状态：历史 ｜ 最后核验：2026-11-23 ｜ 关联：`CHANGELOG.md`

从根目录 `CHANGELOG.md` 原样迁出，条目未改写。0.12.5 及更早见 `before-0.12.6.md`。

## [0.12.10] - 2026-11-14

### Fixed

- 节点概况页「证书状态」不再误报「未签发」：TLS 由外部反代 / Caddy / Tunnel 终结的节点，域名 HTTPS 明明可用也会被判成未签发。
- 判定改为「控制面实测 → Agent 站点探测 → 未知」三级：`GET /nodes/:id/state` 附带 `tls.state`（`verified/failed/none/unknown`），页面优先用它。
- 证书类失败直接显示「证书校验失败：…」；接入地址非 https 显示「未启用 TLS」，不再与「未绑定域名」混为一谈。
- 证书到期日在已知时（Agent 自报或证书库）一并显示，未知时不编造。

## [0.12.9] - 2026-11-14

### Fixed

- Peer 接入命令改用 gzip + base64 内联脚本，体积从 162 KB 降到 49 KB，不再触发 `Argument list too long` 导致新 Peer 无法接入（Agent 0.1.48）。
- 接入命令超过内核单参数上限时返回 `E_COMMAND_TOO_LONG`，不再给出一条必然失败的命令（Agent 0.1.48）。

## [0.12.8] - 2026-11-14

### Fixed

- 「本机监听端口」窄屏行不再重复显示归属进程，改为「端口 · 进程」+「监听地址 · 协议」两行（面板 0.12.8）。

## [0.12.7] - 2026-11-14

### Fixed

- 节点包安装改用 `systemd-run` 跳出 Agent 沙箱，`ProtectSystem=full` 下不再因 `/usr` 只读而失败（Agent 0.1.46）。
- 包安装的 `systemd-run` 分配唯一 `--unit` 并加 `RuntimeMaxSec`，客户端超时后停掉残留单元，不再与新回滚争 dpkg 锁（Agent 0.1.47）。
- `logs.errors` 的 OOM 只统计「killed process」主事件，同一次 OOM 的其他内核行作为上下文附在同一条，不再一次算成 3–4 条（Agent 0.1.47）。
- OOM 计数在节点重启后按新 boot 重新计算，不再漏报；诊断文案改为「自上次查看以来发生过 OOM 杀进程」（Agent 0.1.47 / 面板 0.12.7）。
- 进程列表先按两次采样的 CPU% 排序再截 Top N，刚启动就跑满一核的进程不再被 `ps` 生命周期均值挤出列表（Agent 0.1.47 / 脚本 1.5.4）。
- 对外服务「本机监听端口」只列 TCP LISTEN，不再把系统端口、Caddy 管理口、UDP 服务、站点与转发的对外端口列为可发布；显示归属进程，IPv6 回环预填改为 `[::1]:<port>`（面板 0.1.47 / Agent 0.1.47）。

## [0.12.6] - 2026-11-13

### Added

- 对外服务页列出尚未发布的本机监听端口，点击可预填站点抽屉的上游（面板 0.12.6）。
