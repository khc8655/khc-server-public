# 架构决策记录（ADR）

每个影响架构/契约/数据模型/UI 规范/发版流程的决策，写一篇 ADR。格式：

```markdown
# ADR-000N: 标题
- 状态：提议 / 已接受 / 已废弃 / 被取代
- 日期：YYYY-MM-DD
- 决策者：主人
## 背景
## 选项（≥2，含利弊）
## 决策
## 影响 / 迁移 / 回滚
## 验证
```

命名：`ADR-000N-<kebab-title>.md`，N 从 0001 递增。
