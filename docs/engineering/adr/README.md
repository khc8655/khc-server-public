# 架构决策记录（ADR）

> 状态：现行 ｜ 最后核验：2026-11-13 ｜ 关联：`AGENTS.md` §5

影响架构、契约、数据模型、UI 规范或发版流程的决策，写一篇 ADR。ADR 不归档，被取代时只改状态并写明取代者。

## 模板

```markdown
# ADR-000N: 标题
- 状态：提议 / 已接受 / 已废弃 / 被 ADR-XXXX 取代
- 日期：YYYY-MM-DD
- 决策者：主人
## 背景
## 选项（≥2，含利弊）
## 决策
## 影响 / 迁移 / 回滚
## 验证
```

命名 `ADR-000N-<kebab-title>.md`，编号递增。
