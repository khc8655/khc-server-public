# ADR-0002: 前端按 UI 设计规范 v2.2 重写，不继承旧前端

- 状态：已接受
- 日期：2026-10-26
- 决策者：主人

## 背景

旧前端（7 个模块）功能全但交互不统一；UI 规范 v2.2 已迁入本仓库（`docs/ui/`）。旧仓库 `khc8655/wireguard` 已冻结，仅历史来源。

## 选项

1. 在现有 React 页面上逐步改造：成本低，但会长期保留旧结构/旧交互。
2. 按 v2.2 重写外壳与页面：一次性成本高，但之后加页面有统一模板与组件库。
3. 只借鉴颜色：不满足规范要求。

## 决策

采用选项 2。导入 `docs/ui/` 作为规范副本；`apps/web/src` 按 §7.2 分层（styles/ui/patterns/registry/i18n/data/pages/apps/widgets/dev/gallery）；所有 UI 改动先交变更单（§7.1）。

## 影响 / 回滚

- 现有登录/节点/应用页逐步替换；期间旧页面可保留但不得新增样式。
- 回滚：旧页面代码保留在 git 历史；无需数据迁移。

## 验证

- `dev/gallery` 组件状态页；
- 每页浅/深/390 截图 + 四态；
- PR 按 §7.8 清单逐项勾选。
