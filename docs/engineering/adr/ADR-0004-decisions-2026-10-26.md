# ADR-0004: 2026-10-26 主人拍板事项

- 状态：已接受
- 日期：2026-10-26
- 决策者：主人

## 决策

1. 传输：确认 `fetch + TCP socket` 双通道（详见 ADR-0001）。
2. 默认入口：**`http://<IP 或域名>:8880`**（国内 8443 不可用；Agent 默认 `0.0.0.0:8880`）。隧道保留为可选兜底。
3. 客户端私钥：**控制面加密保存、可重复查看/下载**（简单优先；覆盖 UI 规范 U4 默认值，见 `docs/ui/DECISIONS.md`）。
4. 数据模型：批准新增 `certificates` / `settings`（见 ADR-0003）。
5. 迁移：**全部砍掉**，不做旧 D1/旧备份格式迁移；旧系统仅作为功能参考。

## 影响

- 计划中的“旧备份导入兼容”取消；`plan-v4.md` 相应项标注不做。
- UI 规范 U4 按本决策执行，实现时在 UI 变更单注明安全提示。
- `wrangler` staging 配置与 Agent 安装脚本默认端口同步改为 8880。

## 验证

staging：`http://<IP>:8880` 的 `/state`、配置、plan/apply 全部通过；Agent 安装脚本默认 8880 后 `/health` 可达。
