## 1. 全局层页面

### 1.1 `/login` 登录页（类型 L）

- **目的**：单用户（admin）认证，session cookie。
- **谁/场景**：管理员，session 过期或首次打开，频率极低。
- **首屏**：居中窄卡：产品名 + 密码输入 + [登录]。无任何导航。
- **交互范式**：单表单页，沿用 `LoginShell`。失败 = 表单内联错误（InlineError），不跳页、不弹窗。
- **操作入口**：唯一主按钮 [登录]；回车提交。
- **空态/异常**：密码错误 → 内联"密码不正确"；控制面不可达 → 内联"无法连接控制面"。
- **命名**：标题"登录"，无多余文案。

### 1.2 `/` 全局概览（类型 A · 分诊概览）

- **目的**：回答"整个集群正常吗、有没有要处理的事"。
- **谁/场景**：管理员每次进面板的第一眼，高频。
- **首屏**：
  1. 「需要处理」分诊条（仅在有问题时出现：离线节点、14 天内到期证书，chip 可点直达）；
  2. 3 项集群指标 Stat：节点在线 x/y · 证书总数 · 需要处理数（“未探测节点数”已删除：探测为挂载即发，见 ADR-0014）；
  3. 节点矩阵卡：每节点一卡 = 状态点 + 名称 + 端点 + 线路 + 应用摘要令牌行 + 最近在线，点击进节点概况。
     运行态（CPU/内存/服务）**不**在概览展示，指标只在节点页由 10s 快照轮询提供（ADR-0010）。
     应用摘要（模式 / Peer / 站点 / 转发计数）由控制面 D1 期望配置派生，随 `GET /nodes` 的 `summary` 字段返回，**零节点连接、不占额外请求**；节点实装状态来自同一次 `POST /nodes/probe` 的 `apps`（`/state` 投影，只含名称与布尔值）。
- **摘要令牌规则（2026-11-10；2026-11-11 增补纳管状态）**：显示即开启，只写对象名 + 数字（`Peer N` / `站点 N` / `转发 N`；WireGuard 已开启但 0 Peer 时只写 `WireGuard`）；不写「已开启」前缀，不写「N 个 · N 启用」式重复计数；停用等异常才追加琥珀注记（`· N 停用`）；未配置的项不渲染，全部未配置则整行不出现。**有配置行但条数为 0 时必须显示 `站点 0` / `转发 0`，不得空白**。模式徽标（组网节点 / Caddy 网关）只在有 WireGuard 配置时出现，口径 = D1 期望配置（与节点设置一致）。
- **纳管状态（2026-11-11；同日修正标注语义）**：D1 配置与在线实装做差集——D1 有行但 `installed === false` → 令牌行改显琥珀「内网穿透 / 站点 未安装 / 未生效」且不显示肯定的模式徽标，不得隐藏；节点已安装但 D1 有行且生效条数为 0 → 追加中性「已安装 · 暂无站点」（转发为「已安装 · 暂无规则」，对象名不重复，计数令牌已写 `站点 0` / `转发 0`）；节点已安装但 D1 无该应用行 → 追加中性「· 已安装 · 面板无配置」。**0 站点不等于"未纳管"**：「外部安装 · 未纳管」只在站点页 `caddy_import_scan` 确实返回 `blocks > 0` 时出现（接管入口沿用既有扫描 → 接管），首页与概况页不猜。在线状态缺失（离线 / 未上报）时只显示 D1 口径，不猜。
- **区块顺序**：分诊条 → 指标 → 节点矩阵。**不再**在页头放任何创建按钮。
- **请求预算**：打开一次 = `POST /nodes/probe` 1 次（批量轻量探测，不再逐台 fan-out）+ `GET /nodes` 1 次 + `GET /certificates` 1 次，共 3 次；有离线节点时按 60/120/240 秒最多自动复核 3 次（每次仍只 1 次批量探测），全部在线或手动「刷新状态」即停——单次打开最多 **1+3 次探测**，不做常驻轮询（ADR-0014）。
- **操作入口**：只有导航性质的"进入节点"；无写操作。
- **次要内容**：各节点明细（站点列表、Peer 列表）一律不展示，去节点页看。
- **空态**：无节点 → EmptyState「还没有节点」+ [创建节点]（跳 /hubs）。**异常**：控制面数据加载失败 → InlineError + [重试]。
- **命名**：页面标题"概览"。

### 1.3 `/hubs` 节点列表（类型 B · 列表对象）

- **目的**：节点的增删与接入（安装命令）。
- **谁/场景**：加机器、换机器、重装 Agent 时，低频。
- **首屏**：一张节点表：名称 | 状态 | 接入地址 | 最近在线 | 操作（进入节点）。页头右侧唯一主操作 [＋ 创建节点]，旁边次要操作 [刷新状态]。
- **交互范式**：B 标准 —— 行点击/行内"进入节点"进节点概况；行内第二个动作「删除节点」（L3：确认框内输入节点名解锁）。删除**总是**在删除前生成卸载脚本（控制面生成，不依赖节点在线），删除后脚本留在抽屉内可复制/下载；确认框只保留「同时删除面板代建的 DNS 记录」勾选。节点设置不再提供删除入口。创建走右侧抽屉（创建成功后在同一抽屉显示 token + 安装命令，CodeBlock + CopyButton）。
- **状态三态与刷新边界（2026-11-08）**：状态列只有 在线 / 离线 / 探测中（探测请求整体失败时显示「未知」），**不会把未探测当成离线**。打开页面即自动批量探测一次（`POST /nodes/probe`），15 秒内复用结果；页头 [刷新状态] 强制再探。**离线才自动复核**：探测出不可达节点时按 60s → 120s → 240s 最多再探 3 次，全部在线、手动刷新或离开页面即停（无常驻轮询）；停在后台后回到页面，距上次探测超过 60 秒补探一次。
- **失联标记与清理（2026-11-08）**：本次探测确认不可达、且距 `lastSeenAt` ≥1 天的节点，状态徽标显示「离线 · 已失联 N 天」，表格上方出现警告横幅「N 个节点已失联超过 1 天」+ [删除失联节点]。该按钮直接打开既有 L3 删除确认（输入节点名解锁），并沿用「删除前总生成卸载脚本 / 可勾选清理面板代建 DNS」的逻辑；不新增页面或第二种删除入口。
- **创建抽屉的接入区块（AccessForm，2026-11-07）**：统一为 `node-settings/AccessForm`，与节点设置「修改接入方式」共用同一受控表单与 `toCreatePayload()/toPatchPayload()` 纯函数。字段 = 节点名称（添加与修改都可编辑）+ 接入方式三选一：**域名（ACME）** / **Tunnel** / **IP 直连**。
  - 域名：只用现有 [Zone 下拉] + 「已有解析记录」下拉（只读拉取 A/AAAA/CNAME，不在此新建/修改 DNS）；选中记录后端口默认 443，可选 443/8443/2053/2083/2087/2096，并只读预览 `https://<记录名>[:端口]`；同名冲突/已绑定其他节点的记录置灰。
  - Tunnel：下拉选择 `/api/v1/tunnels` 的全局隧道配置；空态显示「还没有隧道配置」+ 链接到 `/settings?tab=tunnels`；选中后只读展示 `https://<hostname>` 与源站端口，不填端口。服务端按 tunnelId 推导 endpoint，并让安装命令自动注册 cloudflared。
  - IP 直连：主机/IP + 端口（默认 8880）+ 必须勾选「我确认这是明文 HTTP，仅用于内网/测试」；未勾选时保存按钮禁用并提示。
  - 旧「手填 endpoint + CF Zone/子域名 + 隧道地址 + 自签」组合已移除；安装选项只保留 system/user 安装方式与 Caddy 软件包勾选。
  - 创建成功后结果态增加 [我已完成安装]：调用 `POST /nodes/probe` 展示在线/离线，离线时给出 3 条排查提示（DNS/证书、cloudflared/隧道、防火墙放行）；探活失败不阻断抽屉关闭。
  - **删除节点确认文案归属**：`/hubs` 行内删除的 ConfirmAction 文案明确「只删除面板中的节点记录；不会删除全局域名解析记录与隧道配置，之后可复用于其他节点」，并保留「同时删除面板代建的 DNS 记录」勾选作为额外清理。
- **次要内容**：无。
- **空态**：EmptyState + [创建节点]。**异常**：InlineError + [重试]。
- **命名**：对象统一叫"节点"（不再混用 Hub）。

### 1.4 `/settings` 全局设置（类型 B + D）

- **目的**：全局证书库 + 系统变量凭据（如 DNS API key）。
- **谁/场景**：签发/轮换证书、配置 ACME 凭据，中低频。
- **首屏**：Segmented [证书库 | 域名 | 隧道 | 应用目录 | SSH 公钥 | 系统变量]，默认证书库。页头唯一主操作随分段切换（证书库 → 签发或导入；域名 → 添加凭据；隧道 → 添加隧道；应用目录 → 无页头主操作，安装入口在行内；SSH 公钥 → 添加公钥；系统变量 → 添加变量）。路由查询参数 `?tab=domain` / `?tab=tunnels` 可直达；旧 `?tab=cloudflare` 兼容映射到「域名」。
- **应用目录分段（B + D，P2）**：recipe 表：应用 | 版本 | 说明（数据来自构建期 `catalog.generated.json`，随 Agent 包发布）。行点击打开安装抽屉：目标节点选择 + 参数表单（secret 用 password 输入，不写入 D1/日志）+ 抽屉页脚 [安装]（抽屉本身即确认，不二次弹 Dialog）。提交后同一抽屉切换为任务视图：状态/进度 + 日志 + [刷新进度]（不轮询）+ 完成后 access 卡片（CopyButton）。无页头主操作。
- **证书库分段（B）**：证书表：名称 | 域名 | 签发方 | 到期 | 来源 | 操作（导出 / 删除）。页头右侧 [＋ 签发或导入] → 抽屉表单（ACME 签发 / 导入 PEM 二选一）。到期 ≤30 天行内琥珀徽标，≤7 天红。**证书详情抽屉（2026-11-07）**：KeyValue 之后是「安装到节点」卡（节点下拉 + [安装并热重载]，调用 `POST /certs/:id/bind`；明文 http 节点返回 400 并展示原因）与 [续期]（仅 `renewable` 的 ACME 证书；任务进度在抽屉内用 TaskView 展示，完成后原位更新并自动重新安装到来源节点）。节点作用域顶部显示「节点入口（HTTPS）」卡：接入方式 / 入口地址 / Agent TLS 状态 / 证书到期（读 `/state` 的 `agent.tls`；域名接入但 TLS 未启用时给黄色提示）。ACME 签发成功后，若节点接入方式为「域名」则自动执行一次 bind。
- **域名分段（B，2026-11-07）**：命名统一为「域名」，同一分段保留 Cloudflare 凭据/Zone 配置 + 解析记录增改删。凭据表：名称 | 账号 | 已启用 Zone（`n/total`）| Token 状态；一行一条凭据，行点开同一抽屉编辑。抽屉内 Token 只写不读（编辑态只读占位），Zone 用复选列表（不做 Zone→子域名级联）。**每个已勾选 Zone 右侧提供「查看解析记录」展开列表（名称/类型/内容/代理/DNS only/被哪个节点绑定/面板代建），展开时才请求 `/cf-dns/records`，按需加载、不预取**；列表顶部提供 [＋ 添加记录]，在列表上方展开行内新建表单（类型/记录名/内容/代理开关/可选 TTL；记录名可只填子域，自动补当前 Zone），调用 `POST /cf-dns/records/:zoneId` 成功后刷新记录列表；每条 A/AAAA/CNAME 记录行内仅有 [编辑] [删除] 两个按钮：编辑在该记录下方展开行内表单（类型/记录名/内容/代理开关/可选 TTL，不新开第二个抽屉、抽屉内不弹 Dialog），调用 `PATCH /cf-dns/records/:zoneId/:recordId` 成功后刷新记录列表；删除先关闭凭据抽屉，再用页面级 ConfirmAction（L2）确认，调用 `DELETE /cf-dns/records/:zoneId/:recordId`。新增后先拉取全部 Zone 默认全选，再让主人取消不需要的。不新开"域名管理"页面。
- **隧道分段（B + D，2026-11-07）**：全局隧道配置表：名称 | 域名 | 源站端口 | Token 状态 | 更新时间；一行一条配置，行点开同一抽屉编辑。抽屉字段：名称、对外域名、源站端口（默认 8880）、Cloudflare Tunnel Token（编辑时留空 = 保留）；Token 只写不读、加密保存且不回显。删除 = 页面级 ConfirmAction（L2，说明不会删除 Cloudflare 上的 Tunnel/DNS，仍有节点引用时需先改接入方式）。空态提供 [添加隧道]；成功后刷新列表并可选通知节点 AccessForm。面板只保存配置，不调用 Cloudflare API 创建 Tunnel。
- **系统变量分段（B）**：key | 值（密文掩码 + 复制）| 更新时间的表；[＋ 添加变量] → 抽屉（key + JSON value，SecretField）。
- **SSH 公钥分段（B + D，P4）**：全局公钥表：名称 | 指纹 | 注释 | 更新时间；行点击打开重命名抽屉，行内 [删除] 走页面级 ConfirmAction（L2）。添加抽屉：名称 + OpenSSH 单行公钥（服务端校验并计算 fingerprint，重复指纹 409）。只存公钥，私钥永不进入面板；主机运维「添加公钥」对话框提供「从公钥库选择」下拉（按需读取 1 次公钥库，失败不阻塞手动粘贴）。
- **操作入口**：行内可见按钮最多 2 个，其余动作进 `⋯` 菜单；删除证书/变量 = 页面级 ConfirmAction（L2，先关闭抽屉再确认，说明影响哪些站点/功能）。
- **空态**：证书空 → 「还没有证书」+ [签发或导入]；变量空 → 「还没有配置项」。
- **命名**：分区名"证书库""系统变量"；按钮"签发或导入证书"。

### 1.5 `/certs`（暗路由）→ 302 过渡

- 现状：CertificatesPage 的独立路由，无导航入口，与 `/settings?tab=certs` 完全重复。

## 2. 节点层页面

### 2.1 `/hubs/:id` 节点概况（类型 A）

- **目的**：回答"这台节点正常吗、要处理什么"。
- **谁/场景**：进入节点后的第一眼，高频。
- **首屏**：
  1. 离线/异常 Banner（仅异常时）；
  2. 4 指标 Stat：实时状态（在线/离线 + 线路 + Agent 版本）· 站点（总数 + 类型分布，停用才注记）· Peer 在线 x/y（接口名 · 监听端口）· 负载（CPU% + 内存/磁盘摘要）；无数据的 hint 不写占位文案；
  3. 「需要处理」卡（临期证书、failed 服务、长期离线 Peer，chip 可点直达对应页）；
  4. 左「应用与发布」：**只列 D1 已配置的应用**——内网穿透（D1 有 WireGuard 配置）/ 站点（D1 有 caddy-site 行）/ 端口转发（D1 有 port-forward 行）；每行 = 单徽标（运行中 / 未运行 / 待生效 / 未读取）+ 关键参数（接口·地址·端口与 Peer 在线数 / 首个域名与类型 / 首条转发映射）+ 进入链接；右「主机与服务」：系统/内核、运行时长、系统负载、systemd 服务与异常单元。无任何已配置应用时左卡整卡不渲染。证书与接入地址只在底部一行摘要展示，不再占用大块区域。
- **区块顺序**：Banner → 指标 → 需要处理 → 应用与发布 + 主机与服务 → 接入摘要。**删除**现状的"应用发布与证书"明细卡、Peer 区 3 卡与「最近操作」大表（审计后续独立页面）。
- **文案规则（2026-11-10；2026-11-12 B2 收敛）**：与首页令牌同一语言——显示即开启，不写「已开启」前缀与重复计数；未配置项不出现（无「未配置转发」「还没有站点」等负向占位）；已配置但异常时单徽标变「未运行 / 待生效」（琥珀），不叠双徽标、不写解释段。**有配置行但 0 站点/0 规则时仍显示该行（`0 个站点` / `0 条规则`）**；**「未安装」不在概况首屏推断、也不做告警**：行增删与计数只读 D1 `summary`（离线可见、首屏不闪）；在线状态只决定徽标「运行中 / 未运行 / 未读取 / 未安装」：Agent 明确回报 `installed === false` → 中性「未安装」（灰，不红不琥珀）；**只有拿不到状态（`/state` 缺失/失败）才是中性「未读取」**；两者不得合并成一个词。**「外部安装 · 未纳管」只由站点页 `caddy_import_scan` 的 `blocks > 0` 触发，0 站点不等于存在未托管配置**。
- **操作入口**：无创建按钮；卡片右上角放灰色「进入」链接（无箭头）。模式切换入口从概况移到节点设置。
- **空态/异常**：Agent 离线 → Banner + 指标降级为缓存值并标注时间；数据加载失败 → InlineError。
- **命名**：页面标题 = 节点名 + 模式徽标（组网节点 / Caddy 网关）；徽标口径 = D1 期望配置（`GET /nodes/:id` 的 `summary.mode`，离线也可显示），未配置 WireGuard 时不显示；未安装不在首屏推断，不显示「未安装 / 未生效」告警徽标；副标题 = 节点概况 + 站点/Peer 计数（有才写）。

### 2.2 `/hubs/:id/sites` 站点（类型 B + 抽屉表单）

- **目的**：管理这台节点的 Caddy 站点（反代/静态/重定向）。
- **谁/场景**：发布与调整站点，面板最高频写操作。
- **首屏**：
  1. Segmented [站点 | 扩展应用 | 证书]，默认站点；
  2. 站点表：域名 | 类型 | 上游/目标 | **后端** | TLS | 状态 | 操作（编辑）。`后端` 列 ≥1024 为独立列；**<1024（含 390）不隐藏，并入名称列第二段灰字**，形如 `example.com · 内网 VM peer-a 10.9.0.2:3000 · Peer 在线`（后端类型 + Peer 名 + 在线状态都保留），390 仍要求 `scrollWidth === 390`。识别按 `data/services.ts` 单一来源：本机 / 内网 VM / 内网（未登记）/ 外部 / 本机套接字；WireGuard 未安装时 10.x 等私网归「外部」，状态未读取时归「内网（未登记）」；端口转发不参与后端判定。页头右侧：[Caddy 服务]（次操作，抽屉：状态/启动或 reload/校验/导出；服务未运行时主按钮为「启动 Caddy」，运行中为「重载 Caddy」）+ [＋ 添加站点]（唯一主操作）。
- **站点抽屉（新建/编辑）**：分组折叠——默认展开「基本」（域名、类型）+ 类型对应组（反代→上游；静态→目录；重定向→目标）+「TLS」；「安全 / 日志 / 观测」收进底部"高级"折叠。抽屉底部 [保存并生效]。**编辑态**在正文末尾增加「危险操作」卡片：[删除此站点] → 卡片内联确认（Banner + [删除站点]/[取消]，不弹 Dialog），确认后保存并生效并关闭抽屉；行内「删除」入口保留用于快速操作。
- **扩展应用分段（B）**：应用表：名称 | 版本 | 状态 | 配置版本 | 更新时间；行点击进 `/apps/:app` 详情。空态 = 「没有已安装的扩展应用」+ 说明文案。
- **证书分段（只读摘要）**：本节点关联证书表（名称/域名/签发/到期）+ 右上"管理全局证书库"。只读，无操作。
- **次要内容**：批量导入/导出 JSON、清空站点（危险）收进表格下方"高级"折叠区，不占首屏。
- **外部 Caddy 配置分区（B，只读扫描 + 接管）**：站点表下方单独卡片，列出主 Caddyfile 中
  已存在但未托管的站点块（域名/类型/目标/TLS/来源行号/状态）。行内仅「接管为面板站点」
  （L2 确认），行点击打开只读抽屉（原文 + 不可接管原因）。有未应用改动或节点离线时按钮
  禁用并说明；接管失败在卡片顶部显示 Banner + [重试应用] / [恢复 Caddyfile]。无 Caddyfile
  或无外部块时显示说明文案，不新增导航入口。
- **空态**：无站点 → EmptyState「还没有站点」+ [添加站点]。**异常**：Caddy 不可达 → InlineError + [重试]；配置校验失败 → 抽屉内 InlineError，不关闭抽屉。Caddy 未安装 → 顶部 Banner 说明 + [安装 Caddy]（仅 Agent 声明 `capabilities.pkgInstall` 时出现；点击走页面级 ConfirmAction L2，提交后同一 Banner 显示任务 id/状态并提供 [刷新进度]）。
- **命名**：页面标题"站点"；类型徽标：反代 / 静态 / 重定向。

### 2.2a `/hubs/:id/services` 对外服务（类型 B，第 4 批）

- **目的**：一页回答“这台节点对外发布了什么、后端是谁、通不通、有没有待生效”。
- **谁/场景**：发布与日常核对；只读聚合 + 快捷入口，不引入第二种详情/操作入口。
- **首屏**：
  1. 页头标题「对外服务」，**不写解释性副标题**；主操作 [新增站点]（打开现有站点抽屉），次操作 [新增转发]（打开现有转发抽屉）。
  2. 表 A「网页服务」（来源 `caddy-site` 中 `kind=proxy`）：服务 / 对外地址（站点名 + `域名:端口`） | 后端（本机 / 内网 VM + Peer 在线状态 / 内网未登记 / 外部 / 套接字；多上游 `+N`） | 状态 | 证书 / 访问（low） | 操作（行点击开既有站点抽屉，`⋯` 放非详情动作）。
  3. 表 B「远程访问」（来源 `port-forward`）：名称 / 连接地址（`note` 优先，其次 `name` + `主机:端口`） | 目标（内网 VM + Peer 在线） | 状态 | 协议（low） | 操作（行点击开既有转发抽屉，`⋯` 提供复制连接命令/地址）。
  4. 底部一行灰色文字：`另有 N 个跳转/静态站点，见「站点」`；N 为 0 时不渲染。
- **状态与待生效（取第一条命中）**：`appliedRev !== rev` → 未生效（琥珀）；`/state` 未读取/节点离线 → 未读取（灰）；后端 VM 的 Peer 离线 → 后端不可达 / 目标不可达（红）；`siteHealth.state === 'down'` / 转发 `active !== true` → 不可达 / 转发未运行（红）；其余 → 正常 `Nms` / 可连接（绿点，文字默认色）。
- **未生效的行内入口**：状态列右侧直接给 [生效]（复用既有 apply 动作，按 L2 确认）；行内按钮仍 ≤2（[生效] + `⋯`）。不得把「生效」收进 `⋯`。同一 Peer 影响的多行各自标红，概况页合并为一条待办。
- **空态**：表 A 为空 → 整表不渲染；表 B 为空 → 整表不渲染；两张都空 → EmptyState「还没有对外服务」+ 主按钮 [新增站点] + 次按钮 [新增转发]。节点离线 → 两张表按 D1 期望配置渲染，状态统一「未读取」，页头一条中性说明。
- **390**：≤639 表格整体转列表行（名称 + 状态点 / 对外地址 / 后端），不横向滚动（`scrollWidth === 390`）；证书·访问、协议并入文本尾部，不单独占行；名称、状态、行操作永不隐藏。
- **数据与请求**：只用既有 `caddy-site` / `port-forward` / `wireguard` 配置查询与已拉到的 `/state`；**零新增请求、无轮询、无新 D1 表**。后端识别与状态推导唯一实现在 `apps/web/src/data/services.ts`。
- **命名**：页面标题「对外服务」；术语为对外服务 / 网页服务 / 远程访问 / 后端，不写「应用」（避免与「扩展应用」混淆）。

### 2.3 `/hubs/:id/apps/:app` 应用详情（类型 C + D）

- **目的**：单个扩展应用的配置、变更与应用。
- **谁/场景**：装了外部适配器（当前仅 node-exporter）后调配置，低频。
- **首屏**：页头（应用名 + 版本 + 状态徽标 + [保存并生效]）+ Tabs [配置 | 变更 | 任务 | 历史]。
- **配置 Tab（D）**：SchemaForm + 底部 SaveBar（常驻；未改动时禁用并说明）。**变更 Tab**：diff 视图 + [plan]/[应用]。**任务 Tab**：任务表（动作/状态/时间）。**历史 Tab**：rev 列表 + 回滚（L2 确认）。
- **交互范式**：维持现状（已是规范形态），仅统一按钮文案与确认层级；install/uninstall = 页面级 ConfirmAction（L2，先关闭抽屉再确认）。
- **空态/异常**：未安装 → 配置 Tab 顶部 Banner + [安装]；动词失败 → 页面顶部 InlineError 保留数据。

### 2.4 `/hubs/:id/wireguard` 内网穿透（类型 B + 抽屉表单 + E 抽屉）

- **目的**：管理 Peer（WireGuard 客户端）与端口转发，一个页面看全"谁能进来、流量到哪去"。
- **谁/场景**：加手机/电脑进内网、开端口转发，中频。
- **首屏**：
  1. Peer 表：名称 | 隧道地址 | 状态（在线/空闲/已停用）| 最近握手 | 操作（导出配置 · 运维）。页头右侧：[接口设置]（次操作抽屉：接口名固定 khc0、监听端口/MTU/地址段）+ [＋ 添加 Peer]（主操作）。
  2. 下方「端口转发」卡：表（名称 | 监听 | 目标 | 协议 | 状态）+ 卡头右侧 [＋ 添加转发]；有待生效变更时卡上方 Banner [应用更改]。
- **Peer 抽屉（新建/编辑）**：新建保存成功后**同一抽屉**直接显示二维码 + .conf 下载（替代现状"保存后回列表再找导出"）。编辑 Tab：基本信息 / 高级（keepalive、AllowedIPs）。
- **行内「运维」**：打开 Peer 主机运维抽屉（进程 / 防火墙 / SSH 公钥，沿用 PeerOpsPanel 内容，收敛为抽屉内 Tabs）——吸收原 `/peers` 页全部功能。
- **次要内容**：无损换钥与跨节点迁移收进 Peer 抽屉的"高级"区；接口设置在页头次操作。
- **跨节点迁移（2026-11-07）**：Peer 抽屉「高级」区 [迁移到其他节点] → 先关闭 Peer 抽屉，再打开全页唯一迁移抽屉（目标节点下拉，排除当前节点与离线节点）。目标节点未配置内网穿透 / 处于纯网关模式 / 未配置公网地址时，[开始迁移] 禁用并给出原因；有未应用改动时提示会一并应用。执行流程：在目标节点现场生成新密钥（不复用源节点密钥）→ 保存并应用目标节点配置 → 输出覆盖客户端 `/etc/wireguard/khc0.conf` 的一键脚本（CodeBlock + 下载）。源节点 Peer 不自动删除，需人工确认设备已切换后再删。
- **空态**：无 Peer → EmptyState + [添加 Peer]；无转发 → 卡内 EmptyState 一行 + [添加转发]。**异常**：WG 未启用 → 整页替换为启用引导卡（现状已有"未启用卡"，保留并上移为唯一内容）。wireguard-tools 未安装 → 顶部 Banner + [安装 wireguard-tools]（能力驱动，同 Caddy 安装：L2 确认 + 任务状态，不轮询）。
- **命名**：页面标题"内网穿透"；对象名统一"Peer"；"WireGuard"只出现在接口设置等技术语境。

### 2.5 `/hubs/:id/ops` 主机运维（类型 E）

> 已定稿；交互范式见 [ui-guidelines.md §6 类型 E](ui-guidelines.md#6-类型-e--运维动作型)。要点摘录（早期的 [ui-ia-review.md §4](../archive/ui-redesign/ui-ia-review.md) 为历史资料，不作为依据）：

- **首屏**：① 状态带（Agent / CPU / 内存 / 磁盘 / 服务 / 运行，异常才变色，CPU/内存/服务可点击下钻；诊断入口在右侧，仅未通过或检查失败时显示）→ ② Segmented 对象表（服务 / 进程 / 防火墙 / SSH 公钥，防火墙段进入后才连接主机）→ ③ 全页唯一右侧抽屉（进程详情 / 防火墙编辑 / 添加公钥 / 诊断列表 / 诊断详情五种内容）。
- **进程分段（2026-11-03）**：抽屉工具条在排序 Segmented 旁加 [只看业务进程 | 显示全部]（默认只看业务进程），表格下方一行 12px 灰字显示真实隐藏数（业务视图 = 已隐藏 N 个系统进程；全部视图 = 其中 N 个系统进程）。过滤只在 Web 页面层做（`processFilter.ts`，基于 arm-1 / x86-2 实机 `/proc` 观察：内核线程按 ppid=2、系统守护进程按命令首段、系统包路径），不改协议、不动 Agent。
- **操作规则**：行点击 = 详情抽屉；行内动作走"更多操作"菜单；L2 危险操作（删公钥）用页面级 ConfirmAction 确认框；防火墙 `fw.apply` → 60 秒 `fw.confirm` 自动回滚机制保留为表格下方待生效横幅；诊断修复动作直接执行（与应用页"保存并生效"同级，无二级确认）。
- **能力占位**：服务段行内"重启"已注册 `hostOps.svcRestart` 动作但恒禁用并提示"服务重启能力尚未开放"；待 Agent `svc.restart` 白名单 verb 拍板后放开。
- **空态/异常/离线**：动词报错 = 表上方 InlineError 保留数据；观测状态按 ADR-0010 区分三种文案——`实时（10s）`、`无域名 · 仅快照`（经控制面转发）、`已停止自动刷新 · 数据截至 xx:xx`（10 分钟/60 次到顶，附 [刷新一次]）；快照失败保留上一帧并按 10s 重试，状态带标注 `无域名 · 仅快照` 或「实时观测不可用：<原因>；不会自动回退控制面快照」，直连失败时额外提供一次性的 [读取控制面快照]（仅用户显式点击，不改变模式、不重启自动循环）；**不周期拉取 `/state`**（服务/进程等重数据只在打开工作区时取一次 `/state`）；写闸门按 `canApply`。诊断入口保留（控制面侧检查仍可跑）。
- **待新增后端能力**：`svc.restart` 白名单 verb（另有 `svc.logs` 只读 verb 供服务详情日志），需单独确认。

### 2.6 `/hubs/:id/settings` 节点设置（类型 D）

- **目的**：Agent 接入与生命周期、节点模式、备份恢复。
- **谁/场景**：装机、升级 Agent、模式切换、备份，低频但关键。
- **首屏**：顶部 Segmented：[Agent 与接入 | 节点模式 | 备份与恢复]，默认 Agent 与接入。
- **分区内容**：
  - **Agent 与接入**：先「接入方式」卡：右上角徽章按 `node.accessMode` 显示「域名 / Tunnel / IP 直连」（不再用旧的“域名/自定义”二分），内容展示当前入口、绑定域名、隧道配置（名称·域名，按需读取 `/api/v1/tunnels`）或明文入口标记。点 [修改接入方式] 打开全页唯一抽屉，复用与添加节点相同的 `AccessForm`（三种模式、纯函数 `toPatchPayload()`），保存 L1 即时生效；存量节点 `accessMode` 缺省按 endpoint 推导（裸 IP → IP 直连；旧 `preferredRoute='tunnel'` 且无 `tunnelId` → Tunnel 但要求重新选择隧道配置，不允许静默保存）。再 Agent 卡（版本/运行模式/最后在线 + [安装 Agent] [升级 Agent] [卸载 Agent]，命令出抽屉 CodeBlock + CopyButton）。**卸载命令不再要求填写包地址/sha256**（Worker 注入已签名发布包）。安装抽屉对重复安装的覆盖范围做警告说明（覆盖程序/token，保留 `/etc/khc` 应用配置，`--purge` 才删数据）。观测入口由节点 `domain` 自动推导为 `https://<domain>`，本页不再提供手填表单。
  - **节点模式**：当前模式徽标 + [切换…] → 抽屉（预检结果 + 确认，沿用 ModeSwitchDrawer 逻辑）。
  - **备份与恢复**：备份范围说明 + [导出备份] + [导入备份…]（导入 = 页面唯一抽屉内三步：选择文件 → 预览 → 确认，结果在抽屉内展示）。
  - **删除节点**：不在本页；入口统一在 `/hubs` 行内（见 §1.3）。原"SSL 证书与 HTTPS 配置"摘要卡亦已删除（由站点页证书分段承接）。
- **空态/异常**：Agent 离线时安装/卸载命令生成仍可用（控制面本地生成，不依赖节点在线；升级禁用并提示）；模式切换离线禁用并说明原因；备份导入导出为控制面操作，离线仍可用。**接入方式可在离线时修改**，抽屉内明确提示改错会显示离线、可再改回。
- **命名**：页面标题"节点设置"；不再有"与证书"后缀。
