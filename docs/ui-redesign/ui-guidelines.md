# 面板 UI 规范（ui-guidelines）

> 状态：现行 ｜ 最后核验：2026-11-12 ｜ 关联：[page-specs.md](page-specs.md)、[tokens.css](../../apps/web/src/styles/tokens.css)、[参考样例](examples/2026-11-05/demo.html)
> 范围：`apps/web/src` 全部页面与后续 UI 改动
> 总原则：**一页一套范式**。看状态用状态带/指标，看明细用一张对象表，所有详情与操作都进全页唯一的右侧抽屉。
> 轻量约束：只复用 `apps/web/src/ui/` 现有组件（Card / Table / Drawer / Dialog / ConfirmDialog / Banner / Badge / Button / Segmented / KeyValue / Stat / Field / CodeBlock / InlineError / EmptyState / Skeleton / Toast / Menu），**不引入任何重型组件库**（不加 antd/MUI/echarts/xterm 等），不做多层弹窗与重动效。
> **设计令牌唯一权威：`apps/web/src/styles/tokens.css`**（见 §8.8）。本文只写变量名与用途，不复制 hex 值。
> **参考样例（非权威）**：[`examples/2026-11-05/demo.html`](examples/2026-11-05/demo.html)。样例用于对照形态与走查；与本文、`page-specs.md`、`tokens.css` 冲突时，以后三者为准（见 §11）。

## 1. 页面类型总览

| 类型 | 代号 | 适用页面 | 一句话骨架 |
|---|---|---|---|
| 分诊概览型 | A | 全局概览、节点概况 | 分诊条 → 指标 → 待办 → 摘要，只看不操作 |
| 列表对象型 | B | 节点、站点、Peer、转发、证书库、系统变量、扩展应用 | 页头主操作 + 一张对象表，行点击开抽屉 |
| 单对象详情型 | C | 应用详情 | 页头状态 + Tabs（配置/变更/任务/历史） |
| 配置表单型 | D | 全局设置、节点设置、应用配置 Tab、节点设置分区 | 分区表单 + 底部 SaveBar |
| 运维动作型 | E | 主机运维、Peer 运维抽屉 | 状态带 + Segmented 对象表 + 唯一抽屉 |
| 登录页 | L | /login | 居中窄卡单表单 |

## 2. 类型 A · 分诊概览型

**结构模板**：异常 Banner（仅异常时）→ 需要处理分诊条（仅有待办时）→ 指标行（≤4 个 Stat）→ 摘要区（KeyValue / 最近操作表）。

**必须有的区域**：指标区；待办或分诊区（空则不渲染，不占位）。

**状态展示规则**：
- 正常：指标用中性灰数值，不上绿色大字；
- 警告/危险：只在分诊条和对应指标上用琥珀/红徽标，一处告警不重复多处渲染；
- 离线：顶部 Banner + 指标降级为缓存值并标注"xx 前的数据"；
- 加载：Stat 用 Skeleton；空：EmptyState + 唯一引导按钮。

**操作放置规则**：**禁止创建类按钮**（T1 模板只负责看和分诊）；卡片右上只允许"去管理 →"文字链接；待办 chip 点击 = 跳到对应页面。

**禁止事项**：不放明细列表（站点列表、Peer 列表等去专页）；不放推广/文档链接；不超过 4 个指标。

## 3. 类型 B · 列表对象型

**结构模板**：页头（标题 + 对象计数副标题 + 右侧唯一主操作 [＋ 添加 X]）→ （可选）Segmented 分段 → 一张对象表 → （可选）"高级"折叠区。

**必须有的区域**：对象表；主操作按钮；空态。

**状态展示规则**：
- 行内状态列统一用 Badge（ok=已生效/在线，warn=待生效/临期，danger=失败/离线，默认灰=停用）；
- 有待生效变更：表格上方 Banner + [应用更改]，不用弹窗；
- 加载：3 行 Skeleton 表格；空：EmptyState + 主操作；异常：表格上方 InlineError + [重试]，已加载数据保留。

**操作放置规则**：
- 行点击 = 打开对象抽屉（详情或编辑）；行内**可见**按钮 ≤2 个（1 主 1 危），且点击不触发行点击；超过 2 个动作统一收进 `⋯` 菜单（`Table.rowActions`），不并排铺按钮；
- 删除等危险操作：L2/L3 按动作注册表走 ConfirmAction 确认框（见 §8 确认等级）；
- 创建/编辑表单一律在右侧抽屉，不在页面内联展开；
- 低频批量操作（导入/导出/清空）收进表格下方 `高级` 折叠区或页头次操作。

**表格列与密度**：≤6 列；首列对象名（加粗或可点击样式）；IP/地址/版本用等宽字体；行高舒适档（`--h-row`）；表格默认每页 50 行，搜索常驻；不新增第二套滚动/分页。

**文案与按钮命名**：主操作 = "＋ 创建节点" / "＋ 添加{对象名}"；配置保存按是否立即 apply 用"保存并生效"或"保存"；删除确认标题 = "删除{对象名}？"；不写"确定要…吗？"这类废话。

**禁止事项**：同一页面出现两张平级主表（多张表用 Segmented 或上下分卡）；表格里嵌表格；行内超过 2 个按钮。

## 4. 类型 C · 单对象详情型

**结构模板**：页头（对象名 + 版本/状态徽标 + 主操作）→ Tabs（配置 / 变更 / 任务 / 历史）。

**必须有的区域**：对象状态徽标；配置 Tab 的 SaveBar（常驻；未改动时按钮禁用并说明，不隐藏以免布局跳动）。

**状态展示规则**：对象状态在页头徽标一处表达；未安装/未生效用页头 Banner；各 Tab 内部按 B/D 规则。

**操作放置规则**：保存 = 配置 Tab 底部 SaveBar（页头可出现同一"保存并生效"动作，两者必须同 action、同文案、同 loading）；plan/install/uninstall/回滚 = 对应 Tab 或页头动作，危险动作走页面级 L2 确认。

**禁止事项**：Tabs 超过 4 个；在详情页里再开全屏子页。

## 5. 类型 D · 配置表单型

**结构模板**：分区导航（Segmented 或左分区列表，分区 ≤5 个）→ 当前分区表单（Field 纵列）→ 分区底部保存条。

**必须有的区域**：保存条（常驻；未改动时禁用并说明，含"放弃修改"）；危险区独立分区且默认折叠。

**状态展示规则**：保存中按钮 loading；保存成功 Toast；校验失败字段级红字（Field error），不清空输入。

**操作放置规则**：保存按钮在分区底部右侧；危险操作只在"危险区"分区，L3 确认（输入名称）。

**禁止事项**：单页超过 7 个纵向卡片不分区；表单里混入只读状态大屏（状态去 A/E 页）。

## 6. 类型 E · 运维动作型

**结构模板**：① 状态带（一条横条，≤7 格）→ ② Segmented 对象表（服务/进程/防火墙/SSH 公钥等同类对象）→ ③ 全页唯一右侧抽屉。

**必须有的区域**：状态带；对象表；唯一抽屉。

**状态展示规则**：
- 状态带"异常才变色"：正常格灰字，警告琥珀、危险红；阈值集中定义（CPU/内存 ≥90% 红，磁盘 ≥85% 琥珀，有 failed 单元红）；
- 状态带格可点击 = 下钻到对应对象分组；
- 诊断类探查入口放状态带右侧，仅在诊断未通过或检查请求失败时显示；探查内容（诊断、日志、完整命令行）一律在抽屉内；
- 离线：状态带置灰 + 缓存 Banner + 全部操作禁用；加载：状态带骨架 + 表格骨架。

**操作放置规则**：行点击 = 详情抽屉；行内动作走"更多操作"菜单（菜单项可禁用并给出原因）；创建入口在分组表头右侧（仅可创建的对象分组有）；危险操作用页面级 ConfirmAction 确认框（删公钥）或既有特殊机制（防火墙 60 秒确认横幅），确认后结果在同一抽屉内反馈（不新开窗）；诊断修复动作直接执行（loading + 结果反馈，无二级确认）。

**禁止事项**：抽屉里再弹 Dialog；并排多张监控卡；页面上同时出现"状态卡 + 操作按钮组"两套入口。

## 7. 类型 L · 登录页

居中窄卡（≤360px）：产品名 + 密码 Field + [登录]。错误内联，不跳页。无导航、无页脚链接。

## 8. 跨页通用细则

### 8.1 颜色语义（全站唯一）

| 语义 | 用途 | 组件 |
|---|---|---|
| 绿 ok | 在线 / 已生效 / 正常 | Badge(ok)、StatusDot |
| 琥珀 warn | 待生效 / 临期（证书 ≤30 天）/ 需关注 | Badge(warn)、Banner |
| 红 danger | 失败 / 离线 / 危险操作 | Badge(danger)、Banner、Button(danger) |
| 蓝 info | 信息圆点 / 焦点环（2026-11-12 起不再用于徽标底色） | StatusDot(info)、focus |
| 灰 | 未安装 / 未配置 / 未读取 / 停用 / 分类标注 / 次要文字 | 默认 Badge、text-3 |

正常状态不大面积铺绿色；颜色只给异常和分类。**「未安装」「未配置」一律用灰，不用琥珀或红色，也不生成告警 Banner**；只有 Caddy（必装）缺失才算异常。**「未安装」（Agent 明确 `installed === false`）与「未读取」（拿不到 `/state`）是两个词，不得合并**：前者是事实，后者是未知。

### 8.2 确认等级（危险操作三档）

| 等级 | 例子 | 交互 |
|---|---|---|
| L1 普通 | 刷新、添加公钥、保存配置 | 直接执行，Toast 反馈 |
| L2 危险 | 重启服务、删除规则/公钥/证书/Peer、apply、回滚 | ConfirmAction 确认框（说明后果 + [确认] 危险色按钮）；从表格行触发的为页面级确认框 |
| L3 毁灭 | 删除节点、卸载应用、清空站点 | 确认框内输入对象名解锁，按钮常置 danger |

防火墙变更沿用既有特殊机制：`fw.apply` → 60 秒内 `fw.confirm` 否则自动回滚，呈现为表格下方待生效横幅，不算额外弹窗层。

### 8.3 抽屉与对话框边界

- **每页最多一个 Drawer 实例**：详情、编辑、确认、结果反馈全部复用这一个抽屉（换内容不换壳）；同一时刻只允许一个浮层。
- **Dialog/ConfirmDialog 只用于**：无抽屉打开的上下文（全局确认、表格行触发的危险操作确认、L3 输入对象名）。
- **抽屉内禁止再弹 Dialog/ConfirmDialog**。抽屉内的危险动作按以下顺序处理：保存变更 → 关闭抽屉 → 页面级 ConfirmAction → 结果反馈（需要时重新打开同一抽屉）。禁止"抽屉上再盖一层确认框"。
- 抽屉结构固定：标题 `--fs-lg`（对象名 + 状态徽标）/ 上下文行 `--fs-xs` text-3（节点 · 页面）/ 正文（KeyValue + CodeBlock 或表单）/ 底部按钮区（右对齐：取消在左，主操作在右）。
- 抽屉打开时锁定页面滚动、焦点移入抽屉；Esc = 关闭；有未保存修改时先在本抽屉内提示"有未保存修改"，不新开 Dialog。
- 抽屉宽度 `--drawer`（480px）；≤639px 全屏。头部/底部固定，正文区域独立滚动。

### 8.4 时间、单位与格式

- 相对时间：1 分钟内"刚刚"，之后"x 分钟/小时/天前"；超过 30 天显示日期。
- 绝对时间格式 `YYYY-MM-DD HH:mm`（24 小时制）。
- 容量：自动换算 MB/GB，保留整数或一位小数；百分比整数。
- IP/端口/版本/密钥指纹一律等宽字体（mono）；密钥默认掩码 + CopyButton。

### 8.5 错误提示

- 页面级加载失败：InlineError（错误码 + 一句话原因 + [重试]），已加载数据保留不清空。
- 表单校验失败：字段级红字，不弹窗。
- 操作失败：抽屉内或表格上方 InlineError；Toast 只用于成功反馈。
- 错误文案零凭据回显（红线），不出现堆栈。

### 8.6 文案与术语（唯一权威表）

术语以本表为准，本节是术语的唯一出处（旧 IA 审查中的术语段落已并入本节，归档副本不作为依据）。

| 统一文案（UI） | 禁止 / 旧叫法 | 说明 |
|---|---|---|
| 节点 | Hub / hubs / 服务器 | UI 一律"节点"；代码标识 `hubId` 不动 |
| 站点 | 应用发布 / Caddy 站点 | 英文保留 "Sites"；代码标识 `caddy-site` 不动 |
| 扩展应用 | 应用 / apps | 仅指通过适配器安装的应用 |
| 内网穿透 | Peer 组网 / WireGuard 页 | WireGuard 只出现在"接口设置"等技术语境 |
| Peer | Peer 客户端 / 客户端 / Peer 主机 | 对象名统一为 Peer |
| 端口转发 | 转发 / Forward | 对象名统一为"端口转发" |
| 主机运维 | 服务器运维 / 运维 | 节点层页面名 |
| 节点设置 | 节点设置与证书 | 证书摘要不属于设置页标题 |
| 证书库 | SSL 证书库 / 域名证书 / 域名与证书 | 全局设置下的分区名 |
| 保存并生效 | 保存并应用 / 应用 | 保存后立即触发 apply 的配置按钮；仅写草稿不触发 apply 时用"保存"，两者不得混用 |
| 保存 | 提交 / 确定 | 仅写草稿、不立即 apply 的保存按钮 |
| 放弃修改 | 取消修改 / 重置 | SaveBar 次按钮 |
| 创建节点 / 添加{对象} | 新建节点 / 新增 | 节点首次创建用"创建节点"，列表对象用"添加{对象}" |
| 探测中… | 未探测 / 检测中 | 仅表示"本次探测尚未返回"，不是离线证据 |
| 未知 | 探测失败 / 异常 | 仅用于探测请求整体失败（控制面/网络问题），不代表节点离线 |
| 离线 | 不可达 / 连接失败 | 必须有本次探测失败证据或 Agent 明确上报 |
| 已失联 N 天 | 长期离线 / 过期节点 | 离线且距 lastSeenAt ≥1 天；与"离线"同一证据链，只是补充时长 |

**写法规则**：

- 按钮 = 动词开头（添加、导出、重启、删除、刷新）；不用"操作""管理""处理"这类空词。
- 配置按钮二选一：保存后立即 apply 用"保存并生效"（`zh.common.saveAndApply`）；仅写草稿用"保存"（`zh.common.save`）；不得用"提交/确定"代替。
- 每个页面只有一个主操作按钮；次操作用 ghost/text，且不与主操作同色同级。
- 危险确认标题 = "删除{对象}？"；正文写后果与影响范围；不写"确定要…吗？"这类废话。
- 空态标题 = "还没有{对象}"；描述给下一步，不写营销式长句；只放一个引导按钮。
- 错误文案 = 发生了什么 + 影响 + 下一步（如"证书签发失败：DNS 凭据无权限。检查 Cloudflare Token 后重试"）；禁止只写"未知错误"，禁止出现凭据、token、堆栈。
- 状态词只用：在线 / 离线 / 探测中… / 未知（仅探测请求整体失败）/ 已失联 N 天；已生效 / 待生效 / 未生效；启用 / 停用。不得自造"异常""故障中"等含糊词。
- 页面副标题：节点内页面 = 节点名 + 对象计数（如"tyo-1 · 3 个站点"）；全局页 = 全局计数（如"4 个节点 · 2 项需要处理"）；不写说明性长句。
- 英文只保留产品固有词（Peer、Sites、Caddy、Cloudflare），其余用中文。

### 8.7 图标与徽标

- 图标只用 `ui/icons.ts` 现有图标集，不引入图标库；导航与状态点用 7px 圆点（StatusDot）。
- 徽标（Badge）每行最多 2 个；状态列之外不叠徽标。

### 8.8 间距、字号与设计令牌

- **设计令牌唯一权威为 [`apps/web/src/styles/tokens.css`](../../apps/web/src/styles/tokens.css)**（颜色、字号、间距、圆角、阴影等 CSS 变量）。
  - 同步规则：修改令牌 = 修改该文件本身，不新建文档、不在组件里写死绕过令牌的颜色/字号/间距；
  - 旧规范副本（含 v2.2 的 tokens.css）已归档，仅作历史参考，**不得作为取值来源**；
  - 若令牌语义变化影响交互范式（如颜色语义表 §8.1），同 PR 更新本文件对应小节。
- 页面标题 `--fs-xl`(20) / 卡片标题 `--fs-md`(14) / 正文 `--fs-sm`(13) 或 `--fs-md`(14) / 辅助 `--fs-xs`(12)；间距、宽度与内距见 §8.9，字号层级见 §8.10。所有取值引用令牌，不在页面或业务组件写死 px。
- 新增令牌（第二批 + 第三批，取值唯一定义在 `tokens.css`）：`--fs-2xs`（角标/告警等微字号）、`--fs-mono`（等宽数字/代码/密钥）、`--s05`/`--s15`/`--s25`（2/6/10px 半档间距）、`--r-xs`（4px 小圆角）、`--h-control-sm`（26px 小控件高）；`--h-nav`（34px 导航行高）、`--size-dot-sm`/`--size-dot`（6/8px 圆点）、`--size-spinner`（14px 加载指示）、`--size-icon-sm`/`--size-icon-md`/`--size-icon-lg`/`--size-icon-xl`（16/22/32/40px 图标容器）、`--max-popover`（320px 浮层最大高）、`--sidebar-rail`（56px 平板侧栏宽）。组件不得再写这些字面量。
- **保留的组件内部尺寸（有意保留，不是待办）**：`apps/web/src/ui/ui.css` 仍有 59 条尺寸类字面量（列宽、容器宽、min/max 约束、单组件几何、`.ui-kbd` 18px 固定行高）。它们无跨组件复用语义，或收敛必须改变布局；逐条原因见 `docs/verification/2026-11-05/ui-css-token-audit.md` §9.3。新增代码不得再写死。

字号只允许使用 `--fs-*` 令牌；不得新增字号（如 15px、18px、22px、13.5px）。

|---|---|---|---|---|

### 8.12 交互约束

- **行内可见按钮 ≤2**（1 主 1 危）；其余动作进 `⋯` 菜单。表格行的 `rowActions` 一律走菜单，不在单元格并排铺按钮。
- **每页只有一个主操作**；页头次操作最多 1 个，且为 ghost/text。配置页允许同一"保存并生效"动作同时出现在页头与底部 SaveBar，但文案、loading、禁用状态必须完全一致；不得再出现第三个保存入口。
- **唯一详情入口**：行点击进入抽屉/详情；不得同时提供"行点击 + 查看按钮 + 右上角详情链接"三套入口。菜单只放非详情动作（导出、删除、运维等）。
- **确认等级只认动作注册表**：L1 直接执行 + Toast；L2 ConfirmAction（说明后果）；L3 输入对象名解锁。页面不得自行升降级，也不得对 L1 动作加弹窗。
- **禁止抽屉内再弹 Dialog**；危险动作按 §8.3 的"关闭抽屉 → 页面级确认 → 结果反馈"顺序。
- **禁用必须给原因**：`disabledReason`/`title` 或相邻说明，不能只置灰。能力未开放的动作（如服务重启）保持禁用并写明"能力尚未开放"。
- **提交锁**：保存/应用/删除进行中按钮 loading 且不可再次点击；不允许乐观更新主机状态。
- **焦点与键盘**：抽屉/确认框打开时焦点移入，Esc 关闭，关闭后焦点回到触发元素；Tab 不逃出浮层。
- **自动探测只读且有上限**：打开页面只允许读取既有列表/快照；不自动 apply、删除，不自动改写配置。概览与节点列表允许挂载时探测一次 `POST /nodes/probe`（15 秒内复用），发现离线节点时按 60/120/240 秒最多自动复核 3 次，全部在线或手动刷新即停；**每次打开最多 1 次探测 + 3 次复核**，不做常驻轮询（ADR-0014）。

### 8.13 响应式

断点与实现在 `apps/web/src/ui/ui.css`，验收宽度至少覆盖 **1440 / 1024 / 390**。

| 宽度 | 侧栏 | 内容 | 表格 | 抽屉 |
|---|---|---|---|---|
| ≥1024 | 220px 常驻 | 最大 1200，内距 24 | 完整列；low priority 显示 | 480px 右侧 |
| 640–1023 | 56px 图标栏 | 内距 16；3/4 列网格变 2 列 | low priority 列隐藏；其余列保留 | 480px 右侧 |
| ≤639 | 覆盖式抽屉导航 | 内距 12；页头纵向堆叠；操作按钮占满一行 | **表格整体转为列表行**（标题 + 元信息 + 右侧动作），行高 ≥56px | 全屏 |

**390 验收规则**：

- 页面不得出现横向滚动；`documentElement.scrollWidth === 390`。
- 节点/站点等名称不换行挤压；长文本用单行截断 + 详情查看。
- 列隐藏优先级（先隐藏靠后的低优先列）：`updated/time` → `sync` → `version` → 配置版本；名称、状态、行操作永不隐藏。
- 顶栏菜单、搜索/主题入口可见且可点；主题选择保留"浅色/深色/跟随系统"三态。
- 4 宫格指标变 2×2，数值降为 20px；状态带按可用宽度自动换行（单格 min-width 96px），不强制固定列数。
- 触控目标：主按钮 40px（`--h-control-lg`）；`sm` 按钮 32px（`--h-control`）仅用于次要动作；列表行 ≥56px；不得有仅靠 hover 才能触发的操作。

### 8.14 动效与反馈

**允许**（只用令牌）：

| 场景 | 时长 | 缓动 | 形态 |
|---|---|---|---|
| hover / 按钮态 / 分段切换 | `--t-fast` 120ms | `--ease` | 背景、边框、颜色 |
| 抽屉、遮罩、Dialog、菜单 | `--t-base` 200ms | `--ease` | 透明度 + 位移 ≤24px / 缩放 0.96→1 |
| Skeleton | 1.2s | `--ease` | 渐变位移循环 |
| Spinner | 0.7s | linear | 旋转 |

`prefers-reduced-motion: reduce` 时 `--t-fast` / `--t-base` 置 0；不得绕过该媒体查询。

**禁止**：弹簧/回弹、视差滚动、页面过场、自动轮播、持续呼吸/抖动、超过 200ms 的交互过渡、为"好看"加延迟。

**反馈规则**：

- 成功（L1）：Toast，4 秒消失，可悬停暂停；同一时刻只显示 1 条。
- 失败：InlineError（页面/表格/抽屉内），不用 Toast；字段错误贴字段。
- 异步：按钮 loading + 禁用；结果在原上下文呈现，不新开页面。
- 危险操作完成后：结果写在原抽屉/表格上方，并保留可恢复入口（如回滚、重试）。

## 9. 轻量与 Worker 部署约束

1. **组件复用优先**：新页面只允许组合 `apps/web/src/ui/` 现有组件；确需新增的仅限：StatusBar（状态带）、抽屉内 Tabs、EmptyState 变体——均为纯 CSS + 少量 JSX 的轻组件。
2. **不引入依赖**：禁止新增 UI 运行时依赖（组件库、图表库、拖拽库、终端模拟器）。数据展示用表格/Stat/CodeBlock，不画图表。
3. **无重动效**：抽屉/遮罩只做一次 200ms 内的过渡或关键帧（见 §8.14），不用弹簧动画、不做过场。
4. **控制产物体积**：前端构建产物整体应保持小体量（当前量级为数百 KB）；新增页面只加路由级代码分割，不加全局 polyfill。
5. **Worker 侧无负担**：UI 改造不新增 Worker 路由与 D1 表；静态资源由现有方式托管。数据请求沿用现有 `/api/*` 与 `cloudflare:sockets` 双通道，不为 UI 新增实时推送（无 WebSocket/Cron，符合项目定位）。
6. **嵌套层级**：页面 → 卡片 → 表/表单，最多 3 层；抽屉内不再嵌抽屉/弹窗。
